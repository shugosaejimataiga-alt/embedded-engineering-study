## 3. 通信テスターの基本構造

今回使用したデータは3種類。

| 変数 | 役割 |
|---|---|
| `tx` | マイコンに送信するデータ |
| `expected` | 正常なら返ってくるはずのデータ |
| `received` | マイコンから受信したデータ |

### 具体例

```c
uint8_t tx[] = {0x03};
uint8_t expected[] = {0x05, 0x00};
uint8_t received[] = {0x05, 0x00};
```

この場合、

1. `tx`に送信命令を用意する。
2. `expected`に正しい応答を設定する。
3. `received`に受信したデータを用意する。
4. `expected`と`received`を比較する。
5. 一致ならPASS、不一致ならFAILと判定する。

### なぜexpectedが必要なのか

送信したデータと、マイコンから返ってくるデータは必ずしも同じとは限らない。

例えば、温度取得命令を送信すると、マイコンは温度情報を返信する場合がある。

そのため、送信データと受信データではなく、**期待している応答と実際に受信した応答を比較する。**

ただし、送信したデータをそのまま返すエコーバック方式なら、送信データと受信データを直接比較することもできる。

今回はPC上で受信データを設定する模擬通信であり、実際のUART通信は行っていない。

## 4. データ型・bit・byte・16進数

### bitとbyte

- 1bit：0または1を表す情報の単位。
- 1byte：通常8bit。
- `uint8_t`：8ビットの符号なし整数型。
- `uint16_t`：16ビットの符号なし整数型。
- `uint32_t`：32ビットの符号なし整数型。

### データ型と数値の表記方法は別

```c
uint8_t data = 0x03;
```

これは、8ビットの変数に数値3を保存するという意味。

数値3は、以下のように表せる。

| 表記 | 内容 |
|---|---|
| 10進数 | `3` |
| 2進数（8桁表示） | `00000011` |
| 16進数 | `0x03` |

3つとも同じ数値を表す。

16進数はデータ型ではなく、数値の表記方法である。

### 16進数を使う理由

16進数の1桁は4ビットに対応する。

そのため、1バイト（8ビット）の値を16進数2桁で表現できる。

例：

```text
2進数：11111111
16進数：FF
10進数：255
```

通信ログやメモリの内容をバイト単位で確認するとき、16進数は短く表示できるため便利。

ただし、実際の通信では16進数の文字列が送られているわけではなく、ビットの情報が送られる。

## 5. 配列の長さを取得する方法

### sizeofによる要素数の取得

```c
uint8_t expected[] = {0x05, 0x00};

int count1 = sizeof(expected) / sizeof(expected[0]);
```

それぞれの意味は以下のとおり。

```c
sizeof(expected)
```

配列全体のバイト数。

```c
sizeof(expected[0])
```

配列の先頭要素1個のバイト数。

したがって、

**配列全体のバイト数 ÷ 1要素のバイト数 = 要素数**

となる。

この例では、配列の要素数は2。

### sizeofの重要なルール

通常、配列名は多くの式で先頭要素のアドレスに変換される。

しかし、

```c
sizeof(expected)
```

では、配列名がポインタに変換されず、配列全体の大きさを取得できる。

ただし、関数の引数として受け取った配列はポインタとして扱われるため、関数内で同じ計算をしても元の配列の要素数は取得できない。

### size_tについて

`size_t`は、バイト数や配列の要素数などを扱う符号なし整数型。

```c
size_t count = sizeof(expected) / sizeof(expected[0]);
```

`size_t`自体に「バイト」や「個」という単位が付いているわけではない。

今回は要素数を保存している。

また、`sizeof`の結果の型は`size_t`である。

今回の演習では、関数の引数の指定に合わせて`int`型で要素数を扱った。

## 6. 配列とポインタの関係

今回、特に理解を深めた部分。

```c
uint8_t expected[] = {0x05, 0x00};
```

| 表記 | 意味 |
|---|---|
| `expected` | 通常の式では先頭要素のアドレスに変換 |
| `*expected` | 先頭要素の値 |
| `expected[0]` | 先頭要素の値 |
| `expected[1]` | 2番目の要素の値 |
| `&expected[0]` | 先頭要素のアドレス |
| `&expected` | 配列全体を指すアドレス |

### 関数への配列の受け渡し

```c
int checkResponse(uint8_t expected[], int count1,
                  uint8_t received[], int count2);
```

C言語では、関数の引数における配列宣言はポインタとして扱われる。

そのため、次の宣言と同じ意味になる。

```c
int checkResponse(uint8_t *expected, int count1,
                  uint8_t *received, int count2);
```

どちらも受け取るのは配列の先頭要素のアドレス。

### ポインタから値を取得する

```c
expected[i]
```

これは次の表記と同じ。

```c
*(expected + i)
```

先頭アドレスからi要素分進んだ場所の値を取得する。

### 今回理解したこと

関数には配列の先頭アドレスと要素数を渡す。

関数側では、渡された要素数を使用して、各要素にアクセスできる。

ただし、先頭アドレスだけでは配列全体の長さを知ることはできない。

## 7. 配列の比較処理

今回の中心となった機能。

### 要求仕様

- 2つの配列の要素数が違えば不一致。
- 要素数が同じでも、1つでも値が異なれば不一致。
- 長さとすべての値が一致すれば合格。

### 実装した関数

```c
int checkResponse(uint8_t expected[], int count1,
                  uint8_t received[], int count2)
{
    if (count1 != count2) {
        return 0;
    }

    for (int i = 0; i < count1; i++) {

        if (expected[i] != received[i]) {
            return 0;
        }
    }

    return 1;
}
```

### 処理の流れ

**① 配列の長さを確認**

```c
if (count1 != count2) {
    return 0;
}
```

要素数が違えば、その時点で関数を終了する。

**② 配列の各要素を確認**

```c
for (int i = 0; i < count1; i++) {
    if (expected[i] != received[i]) {
        return 0;
    }
}
```

同じ位置の値を順番に比較する。

1つでも異なる値があれば、`return 0;`で関数を終了する。

**③ すべて一致した場合**

```c
return 1;
```

最後まで不一致がなければ、合格とする。

### 今回理解した重要なこと

`return`は単に値を返すだけではなく、その時点で関数を終了する。

そのため、for文の中で不一致を見つけたら、それ以上比較せずに終了できる。

また、for文の中にif文を置き、繰り返すたびに判定する方法を理解した。

## 8. printfによる16進数表示

### %02X

```c
printf("%02X\n", (unsigned int)tx[i]);
```

| 記号 | 意味 |
|---|---|
| `%` | 書式指定の開始 |
| `0` | 空いた桁を0で埋める |
| `2` | 最低2桁の表示幅 |
| `X` | 符号なし整数を16進数の大文字で表示 |

例：

```text
数値3   → 03
数値10  → 0A
数値255 → FF
```

`%X`だけなら、数値3は`3`と表示される。

`%02X`なら`03`と表示される。

なお、`%02X`だけで`0x`という接頭辞が表示されるわけではない。

### (unsigned int)について

```c
(unsigned int)tx[i]
```

これは型キャストであり、`tx[i]`の値を`unsigned int`型へ変換する。

現在のMSYS2 UCRT64環境では、

- `uint8_t`：8ビット
- `unsigned int`：32ビット

となる。

ただし、型キャストをしても数値そのものは変わらない。

`printf`の`%X`は、`unsigned int`型の値を16進数で表示する書式指定子である。

その型に明示的に合わせるために、

```c
(unsigned int)
```

を使用した。

今回の`uint8_t`ではキャストなしでも正しく表示できるが、書式指定子との型の対応を明確にするために使用した。

**重要：型キャストと16進数表示は別の処理。**

- `(unsigned int)`：データ型を変換する。
- `%02X`：整数を16進数で最低2桁表示する。

## 9. 学習中に発生したエラーと修正

### ① 変数の未宣言

エラー：

```text
'count1' undeclared
```

原因：

```c
count1 = sizeof(expected) / sizeof(expected[0]);
```

`count1`を宣言せずに使用していた。

修正：

```c
int count1 = sizeof(expected) / sizeof(expected[0]);
```

### ② ポインタの型の不一致

エラー：

```text
incompatible pointer type
```

原因：

`unsigned char`型の配列を、`int *`型の引数で受け取ろうとしていた。

修正：

配列の要素型と、関数で受け取るポインタの指す型を合わせる。

今回は`uint8_t`に統一した。

### ③ if文の条件式にfor文を書いた

誤った考え方：

```c
if (count1 == count2 && for (...))
```

`&&`の右側に、そのままfor文を書くことはできない。

修正した考え方：

1. if文で配列の長さを比較する。
2. for文で要素を順番に確認する。
3. for文内のif文で不一致を判定する。

### ④ != と ! の混同

誤り：

```c
if (!count1 == count2)
```

正しい書き方：

```c
if (count1 != count2)
```

- `!`：論理否定
- `!=`：等しくないか比較する演算子

### ⑤ uint8_t charという宣言

誤り：

```c
uint8_t char data[] = {0x03};
```

正しい書き方：

```c
uint8_t data[] = {0x03};
```

`uint8_t`自体がデータ型なので、`char`を追加する必要はない。

### ⑥ printfのセミコロン忘れ

C言語の文末には原則として`;`が必要。

### ⑦ 未使用変数の警告

```text
warning: unused variable 'tx'
```

`tx`を宣言していたが、プログラム内で使用していなかった。

TXの表示処理を追加することで、実際に利用するように修正した。

### 再実装したコード

```c
#include <stdio.h>
#include <stdint.h>

int checkResponse(uint8_t expected[], int count1,
                  uint8_t received[], int count2);

int main(void)
{
    uint8_t tx[] = {0x10, 0x20};
    uint8_t expected[] = {0x30, 0x40};
    uint8_t received[] = {0x30, 0x40};

    int count1 = sizeof(expected) / sizeof(expected[0]);
    int count2 = sizeof(received) / sizeof(received[0]);
    int count3 = sizeof(tx) / sizeof(tx[0]);

    int result = checkResponse(expected, count1,
                               received, count2);

    if (result == 1) {
        printf("PASS\n");
    } else {
        printf("FAIL\n");
    }

    for (int i = 0; i < count1; i++) {
        printf("%02X\n", (unsigned int)expected[i]);
    }

    for (int i = 0; i < count2; i++) {

        }
```
