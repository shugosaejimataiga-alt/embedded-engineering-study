# 今日学んだこと

## 1. RAM

RAMは、

**Random Access Memory**

の略。

CPUが現在の処理で必要としているデータやプログラムを、一時的に置いておく記憶装置。

例えば、SSDに保存されているアプリを起動すると、必要なプログラムやデータがRAMへ読み込まれる。

CPUは、そのRAMに置かれている命令やデータを使って処理を行う。

RAMは**揮発性メモリ**である。

そのため、RAMへの電力供給が止まると、RAMに保存されていた内容は消える。

### RAMのポイント

* Random Access Memory
* 現在の作業に必要なデータやプログラムを一時的に置く
* CPUが処理するときに使用する
* 揮発性
* 電力供給が止まると内容が消える

---

## 2. ROM

ROMは、

**Read Only Memory**

の略。

機械の基本的・固定的な処理に使用するプログラムなどを保存するためのメモリ。

RAMとは違い、普段の作業用として頻繁に内容を入れ替えるためのものではない。

ROMは**不揮発性メモリ**である。

そのため、電力供給が止まっても保存されている内容は残る。

### ROMのポイント

* Read Only Memory
* 機械の基本的・固定的なプログラムなどを保存する
* 不揮発性
* 電力供給が止まっても内容が残る

なお、現在は「ROM」と呼ばれていても、Flash ROMなど実際には書き換え可能なものも存在する。

---

## 3. SSD

SSDは、

**Solid State Drive**

の略。

ファイル、写真、動画、OS、アプリ、プログラムなどを長期間保存するための記憶装置。

RAMとは違い、作業中だけ使うものではなく、電源を切ったあとも残しておきたいデータを保存する。

SSDは**不揮発性**である。

そのため、電力供給が止まっても保存されているデータやプログラムは消えない。

SSDでは、**半導体メモリに電気的にデータを保存する。**

内部で磁気ディスクを回転させる必要はない。

### SSDのポイント

* Solid State Drive
* 長期保存用
* ファイル、写真、OS、アプリなどを保存する
* 不揮発性
* 電力供給が止まっても内容が残る
* 半導体メモリに電気的に保存する

---

## 4. HDD

HDDは、

**Hard Disk Drive**

の略。

SSDと同じように、ファイル、写真、動画、OS、アプリなどを長期間保存するための記憶装置。

HDDも**不揮発性**である。

そのため、電力供給が止まっても保存されている内容は残る。

SSDとHDDの大きな違いは、**データを保存する仕組み**。

SSDは半導体メモリに電気的に保存する。

HDDは、内部にある**磁気ディスクを回転させ、磁気を利用してデータを読み書きする。**

### HDDのポイント

* Hard Disk Drive
* 長期保存用
* SSDと役割はほぼ同じ
* 不揮発性
* 電力供給が止まっても内容が残る
* 磁気ディスクを回転させて読み書きする

---

## 5. SSDとHDDの違い

SSDとHDDは、どちらも長期保存用の記憶装置。

違いは主に保存方式。

### SSD

`半導体メモリに電気的に保存`

### HDD

`磁気ディスクを回転させて読み書き`

つまり、

**SSDとHDDは役割は似ているが、データを保存する仕組みが違う。**

---

## 6. 揮発性と不揮発性

今日、記憶装置を理解するうえで重要だったのが、

**揮発性**

と

**不揮発性**

という考え方。

ここでいう「電源を切る」とは、正確には、

**その記憶装置への電力供給が止まる**

という意味。

### 揮発性

電力供給が止まると、保存されていた内容が消える。

例：

* RAM
* キャッシュ

### 不揮発性

電力供給が止まっても、保存されていた内容が残る。

例：

* ROM
* SSD
* HDD

---

## 7. キャッシュ

キャッシュは、

**CPUがよく使うデータやプログラムを一時的に置いておく、高速な記憶領域。**

RAMには、現在の作業で必要なデータやプログラムが置かれている。

そのRAMにあるものの中でも、CPUが何度も使う可能性が高いデータなどをキャッシュに置く。

CPUが毎回RAMまでデータを取りに行くより、CPUの内部または非常に近い場所にあるキャッシュから取り出した方が速い。

そのため、CPUの処理速度を上げることができる。

キャッシュもRAMと同じく**揮発性**である。

電力供給が止まると内容は消える。

### キャッシュのポイント

* CPUがよく使うデータなどを一時的に置く
* RAMより高速
* CPUの内部または非常に近い場所にある
* RAMまでデータを取りに行く回数を減らせる
* CPUの処理を高速化する
* 揮発性
* 電力供給が止まると内容が消える

---

# RAMとキャッシュの違い

RAMとキャッシュは、どちらも一時的にデータやプログラムを置く。

ただし役割が違う。

### RAM

現在の作業で必要なデータやプログラムを広く置いておく。

### キャッシュ

RAMにあるものの中でも、CPUがよく使うものを高速に取り出せるように置いておく。

イメージとしては、

`RAM = 作業机`

`キャッシュ = 手元に置いている資料`

CPUが何度も使うものを手元に置くことで、処理を速くする。

---

# 記憶装置からCPUまでの流れ

大きく単純化すると、

`SSD / HDD → RAM → キャッシュ → CPU`

という流れになる。

## ① SSD / HDD

プログラムやデータを長期間保存している。

例えば、

* OS
* アプリ
* ファイル
* 写真
* 動画

など。

↓

## ② RAM

SSDやHDDに保存されているものの中から、

**現在の処理で必要なプログラムやデータがRAMへ読み込まれる。**

RAMは現在の作業用の一時的な記憶場所。

↓

## ③ キャッシュ

RAMにあるものの中でも、

**CPUがよく使うデータなどがキャッシュに置かれる。**

CPUの近くに置くことで、RAMまで取りに行く回数を減らし、処理を速くする。

↓

## ④ CPU

CPUが命令やデータを処理する。

CPUでは以前学習した、

`フェッチ → デコード → 実行`

という流れで命令が処理される。

CPUには、

* CU（Control Unit / 制御装置）
* ALU（Arithmetic Logic Unit / 算術論理演算装置）

などがある。

---

# 全体整理

| 種類    | 主な役割                    | 電力供給停止後 | 保存方式・特徴               |
| ----- | ----------------------- | ------- | --------------------- |
| RAM   | 現在の作業に必要なデータ・プログラムを一時保存 | 消える     | 作業用の一時記憶              |
| ROM   | 機械の基本的・固定的なプログラムを保存     | 残る      | 基本的に固定的な内容            |
| SSD   | ファイル・OS・アプリなどを長期保存      | 残る      | 半導体メモリに電気的に保存         |
| HDD   | ファイル・OS・アプリなどを長期保存      | 残る      | 磁気ディスクを回転させて読み書き      |
| キャッシュ | CPUがよく使うデータなどを一時保存      | 消える     | CPUの内部または近くにある高速な記憶領域 |
