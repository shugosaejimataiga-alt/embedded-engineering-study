# 今日学んだこと

## 1. bit

bitは、コンピュータが扱う情報の最小単位である。

1bitでは、

```text
0
```

または

```text
1
```

のどちらか1つを表す。

例えば、

```text
1011
```

は4つのbitで構成されているため、4bitである。

---

## 2. Byte

Byteは、8bitを1まとまりにした単位である。

```text
1Byte = 8bit
```

そのため、

```text
8bit  = 1Byte
16bit = 2Byte
24bit = 3Byte
32bit = 4Byte
```

となる。

### bit → Byte

```text
bit数 ÷ 8
```

### Byte → bit

```text
Byte数 × 8
```

---

## 3. KB

KBは、Byteより大きな容量を表す単位である。

```text
1KB = 1000Byte
```

例：

```text
5KB = 5000Byte
```

---

## 4. MB

MBは、KBより大きな容量を表す単位である。

```text
1MB = 1000KB
```

つまり、

```text
1MB
= 1000KB
= 1,000,000Byte
```

となる。

---

## 5. GB

GBは、MBより大きな容量を表す単位である。

```text
1GB = 1000MB
```

つまり、

```text
1GB
= 1000MB
= 1,000,000KB
= 1,000,000,000Byte
```

となる。

---

# 容量単位の順番

```text
bit → Byte → KB → MB → GB
```

bitとByteの間だけは8倍・8分の1で変換する。

```text
8bit = 1Byte
```

Byte以降の10進系の単位では、1段階ごとに1000倍または1000分の1になる。

```text
1KB = 1000Byte
1MB = 1000KB
1GB = 1000MB
```

---

# 大きい単位と小さい単位の変換

## 大きい単位 → 小さい単位

基本的に掛け算をする。

例：

```text
GB → MB
× 1000

MB → KB
× 1000

KB → Byte
× 1000

Byte → bit
× 8
```

---

## 小さい単位 → 大きい単位

基本的に割り算をする。

例：

```text
bit → Byte
÷ 8

Byte → KB
÷ 1000

KB → MB
÷ 1000

MB → GB
÷ 1000
```

---

# KB・MB・GBとKiB・MiB・GiBの違い

データ容量には、10進数を基準にした単位と2進数を基準にした単位がある。

## 10進系

```text
1KB = 1000Byte
1MB = 1000KB
1GB = 1000MB
```

KB、MB、GBは1000を基準としている。

---

## 2進系

```text
1KiB = 1024Byte
1MiB = 1024KiB
1GiB = 1024MiB
```

KiB、MiB、GiBは1024を基準としている。

1024は、

```text
2^10 = 1024
```

であり、2進数を扱うコンピュータと相性の良い値である。

---

# 10進系と2進系の整理

```text
10進系

1KB = 1000Byte
1MB = 1000KB
1GB = 1000MB
```

```text
2進系

1KiB = 1024Byte
1MiB = 1024KiB
1GiB = 1024MiB
```

KBとKiB、MBとMiB、GBとGiBは同じ単位ではないため、区別する必要がある。

---

# 複数段階の容量変換

容量を複数の単位をまたいで変換するときは、一段階ずつ変換すればよい。

例：

```text
4MB
↓ ×1000
4000KB
↓ ×1000
4,000,000Byte
↓ ×8
32,000,000bit
```

逆方向なら、

```text
16,000,000bit
↓ ÷8
2,000,000Byte
↓ ÷1000
2000KB
↓ ÷1000
2MB
```

となる。
