# 今日やった問題

## 問題1

4bitでは、bitの組み合わせは全部で何通りあるか。また、4bit signedで扱える整数の範囲を求める。

### 解答

4bitなので、

```text
2^4 = 16通り
```

のbitパターンがある。

unsignedの場合は、

```text
0 ～ 15
```

の16通り。

signedの場合は、

```text
-2^(n-1) ～ 2^(n-1)-1
```

なので、4bitでは、

```text
-2^(4-1) ～ 2^(4-1)-1

= -8 ～ 7
```

の16通りとなる。

## 問題2

4bit signedで `-3` を2進数で表す。

### 解答

まず3を4bitの2進数にする。

```text
3 = 0011
```

全bitを反転する。

```text
0011
↓
1100
```

1を足す。

```text
1100
+   1
-----
1101
```

したがって、

```text
-3 = 1101
```

# Day7で学んだこと

## 1. bit数と組み合わせの数

n bitでは、

```text
2^n
```

通りのbitパターンを表すことができる。

4bitなら、

```text
2^4 = 16通り
```

となる。

重要なのは、

```text
2^n
```

で分かるのは「何通りのbitパターンが存在するか」であり、それぞれのbitパターンをどの整数として扱うかはsigned / unsignedなどの解釈によって変わるということ。

---

# 2. unsignedとsigned

同じ4bitでも、unsignedとsignedでは扱う整数が異なる。

## unsigned

負の数を扱わず、0以上の整数として16通りすべてを使う。

```text
0000 = 0
0001 = 1
...
1111 = 15
```

範囲は、

```text
0 ～ 2^n - 1
```

4bitなら、

```text
0 ～ 15
```

となる。

---

## signed

負の数・0・正の数を扱う。

一般的な2の補数表現では、

```text
-2^(n-1) ～ 2^(n-1)-1
```

となる。

4bitなら、

```text
-8 ～ 7
```

となる。

つまり、

```text
4bit
→ 16通りのbitパターン

unsigned
→ 0 ～ 15

signed
→ -8 ～ 7
```

となる。

---

# 3. signedの先頭bit

2の補数表現のsigned整数では、

```text
先頭bitが0
→ 0または正の数

先頭bitが1
→ 負の数
```

として判断する。

例：

```text
0110
```

は先頭bitが0なので、

```text
6
```

となる。

一方、

```text
1010
```

は先頭bitが1なので負の数として読み取る必要がある。

---

# 4. 補数とは

補数とは、

```text
目的となる値にするために、
元の数に対して不足している分を補う数
```

という考え方。

Day7では特に「2の補数」を学んだ。

---

# 5. 2の補数とは

今回理解した2の補数の考え方は、

```text
2進数において、
元の数に足すことで、
決められたbit数の中では0になるように補う数
```

である。

例えば4bitで3の場合、

```text
3 = 0011
```

3を打ち消して0にするbit列は、

```text
1101
```

となる。

実際に足すと、

```text
  0011
+ 1101
------
 10000
```

となる。

しかし4bitでは5桁目を保持できないため、左端の1があふれる。

```text
10000
↓
0000
```

したがって、4bitの中では、

```text
0011 + 1101 → 0000
```

となる。

数学では、

```text
3 + (-3) = 0
```

なので、signedでは、

```text
1101
```

を `-3` の表現として利用する。

---

# 6. 「2の補数」という名前

「2」は2進数の「2」。

「補数」は、元の値を打ち消すために補う数という意味。

つまり、

```text
2の補数
= 2進数で元の値を打ち消すために補う数
```

と理解した。

---

# 7. 2の補数を求める方法

実際に計算するときは、

```text
bitを反転
↓
1を足す
```

ことで2の補数を求められる。

例えば4bitの3なら、

```text
3 = 0011

反転
1100

+1
1101
```

となる。

したがって、

```text
4bitにおける3の2の補数 = 1101
```

であり、4bit signedでは、

```text
-3 = 1101
```

として扱う。

---

# 8. 負の10進数をsignedのbit列へ変換する方法

例えば4bit signedで `-5` を表したい場合、

まずマイナスを外す。

```text
-5
↓
5
```

5を4bitの2進数にする。

```text
5 = 0101
```

bitを反転する。

```text
0101
↓
1010
```

1を足す。

```text
1010
+   1
-----
1011
```

したがって、

```text
-5 = 1011
```

となる。

手順：

```text
負の10進数
↓
マイナスを外す
↓
決められたbit数の2進数にする
↓
全bitを反転
↓
+1
↓
負の数を表すbit列
```

# 9. signedのbit列から負の10進数を求める方法

例えば4bit signedの、

```text
1011
```

を読む。

先頭bitが1なので負の数。

bitを反転する。

```text
1011
↓
0100
```

1を足す。

```text
0100
+   1
-----
0101
```

`0101` を10進数にすると、

```text
5
```

なので、マイナスを付ける。

```text
1011 = -5
```

手順：

```text
signedのbit列
↓
先頭bitを確認

0なら
→ そのまま読む

1なら
→ 反転
→ +1
→ 10進数に変換
→ マイナスを付ける
```

# 11. 2の補数を使う意味

2の補数を使うことで、コンピュータは負の数をbitで表現できる。

さらに、正の数と負の数を普通の2進数の加算として処理できる。

例えば、

```text
3 + (-3)
```

では、

```text
3  = 0011
-3 = 1101
```

なので、

```text
  0011
+ 1101
------
 10000
```

4bitでは左端の1があふれるため、

```text
0000
```

となる。

したがって、

```text
3 + (-3) = 0
```

をbitの加算でも実現できる。

# 12. 組み込み開発で2の補数を使う場面

組み込みでは、センサーや通信などからbit列そのものを扱う場合がある。

例えば8bitで、

```text
11111011
```

というデータを受け取った場合、

unsignedとして読めば、

```text
251
```

となる。

しかし、これが8bit signedの2の補数表現である場合、

```text
11111011
↓ 反転
00000100
↓ +1
00000101
↓
5
```

なので、

```text
-5
```

となる。

つまり、

```text
同じbit列でも

uint8_tなら
11111011 = 251

int8_tなら
11111011 = -5
```

という違いがある。

センサー値、通信データ、メモリ、デバッガなどでbit列を見るときに、signed / unsignedと2の補数を理解していることが重要になる。

---

# 13. 2の補数を速く求める別の考え方

基本は、

```text
反転 → +1
```

で求めればよい。

ただし、n bitのsignedで先頭bitが1の場合、

```text
unsignedとして読んだ値 - 2^n
```

でも同じ値を求めることができる。

例えば8bitの、

```text
11111011
```

はunsignedでは251。

8bitなので、

```text
2^8 = 256
```

よって、

```text
251 - 256 = -5
```

となる。

ただし、現在の学習ではまず、

```text
反転 → +1
```

の基本的な方法を確実に理解する。

# Day7で理解した全体像

変数のデータ型にはbit数が割り当てられている。

そのbit数によって、

```text
2^n
```

で扱えるbitパターンの組み合わせ数が決まる。

そのbitパターンに対して数字を割り当てて表現する。

unsignedでは0以上の整数を扱い、signedでは負の数・0・正の数を扱う。

signedの0以上の値は、通常の2進数と同じように読むことができる。

一方、signedの負の数については、2の補数を使ってbitで表現する。

2の補数とは、

```text
2進数で元の値を打ち消し、
決められたbit数の中で0にするために補う数
```

である。

実際の計算では、

```text
bit反転
↓
+1
```

によって求められる。

負の10進数からbit列を求める場合も、bit列から負の10進数を求める場合も、この仕組みを利用できる。
