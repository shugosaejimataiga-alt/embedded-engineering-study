# C-Day18：配列と関数

## 学習内容

Day18では、配列に保存した複数のデータを関数へ渡し、関数の中で処理する方法を学習した。

主に以下を学んだ。

- 配列を関数へ渡す方法
- 配列の要素数を関数へ渡す理由
- 配列とfor文の組み合わせ
- 配列の合計値を求める方法
- 配列の平均値を求める方法
- 配列の最大値を求める方法
- 配列の最小値を求める方法
- 配列を関数へ渡す際の型
- intとdoubleの使い分け
- 計算時の型変換（キャスト）
- 変数を初期化する必要がある場合とない場合

---

## 1. 配列を関数へ渡す

配列は関数の引数として渡すことができる。

例：

```c
void show_data(int data[], int size)
{
    for (int i = 0; i < size; i++) {
        printf("%d\n", data[i]);
    }
}
````

呼び出し側では、

```c
show_data(data, 5);
```

のように、

* 配列
* 配列の要素数

を一緒に渡す。

---

## 2. 配列だけでは要素数が分からない

関数に配列を渡した場合、関数側では基本的にその配列が何個の要素を持っているのか分からない。

そのため、

```c
void show_data(int data[], int size)
```

のように、要素数も別の引数として渡す。

ここで、

```c
int data[]
```

は配列を受け取るための引数、

```c
int size
```

は配列の要素数を受け取るための引数。

---

## 3. 要素数と添字の違い

例えば、

```c
int data[5];
```

の場合、

要素数は5個。

使用できる添字は、

```text
0
1
2
3
4
```

となる。

つまり、

```text
要素数 = 5
最大の添字 = 4
```

であり、

```text
最大の添字 = 要素数 - 1
```

となる。

そのため、配列をfor文で処理するときは、

```c
for (int i = 0; i < size; i++)
```

とする。

```c
i <= size
```

にすると、最後に範囲外の要素へアクセスしてしまう。

---

## 4. 配列とfor文

配列に保存された複数のデータは、for文を使うことで順番に処理できる。

```c
for (int i = 0; i < size; i++) {
    printf("%d\n", data[i]);
}
```

`i` を添字として利用することで、

```text
data[0]
data[1]
data[2]
...
```

という順番で各要素へアクセスできる。

---

## 5. 配列の合計値を求める

合計値を求める場合は、合計を保存する変数を用意する。

```c
int total = 0;
```

そして、

```c
for (int i = 0; i < size; i++) {
    total = total + data[i];
}
```

とする。

例えば、

```text
10
20
30
40
```

なら、

```text
最初
total = 0

0 + 10 = 10
10 + 20 = 30
30 + 30 = 60
60 + 40 = 100
```

となる。

---

## 6. `total = data[i]` では合計にならない

以下のようにすると、

```c
total = data[i];
```

毎回値が上書きされる。

例えば、

```text
10
20
30
40
```

なら、

```text
total = 10
total = 20
total = 30
total = 40
```

となり、最終的には40しか残らない。

合計する場合は、

```c
total = total + data[i];
```

とする必要がある。

つまり、

```text
total = data[i]
→ 上書き

total = total + data[i]
→ それまでの値に積み上げる
```

という違いがある。

---

## 7. 計算結果は戻り値として返せる

合計値などを求める関数では、関数内部で表示するだけでなく、計算結果をreturnで返すことができる。

```c
int add(int data[], int size)
{
    int total = 0;

    for (int i = 0; i < size; i++) {
        total = total + data[i];
    }

    return total;
}
```

呼び出し側では、

```c
int total;

total = add(data, 5);
```

のように受け取る。

計算する関数では、

```text
計算する
↓
returnで結果を返す
↓
main側で受け取る
```

という形にすると、関数の役割を分けやすい。

---

## 8. 平均値を求める

平均値は、

```text
合計値 ÷ 要素数
```

で求める。

重要なのは、すべての要素を合計してから最後に割ること。

```c
double average(int data[], int size)
{
    double total = 0;

    for (int i = 0; i < size; i++) {
        total = total + data[i];
    }

    return total / size;
}
```

for文の途中で毎回割ってはいけない。

正しい流れは、

```text
すべて足す
↓
合計を求める
↓
最後に要素数で割る
```

となる。

---

## 9. 平均値ではdoubleを使う

平均値は小数になる可能性がある。

例えば、

```text
77 ÷ 6 = 12.833333...
```

そのため、平均値を返す関数の戻り値は、

```c
double
```

にする。

```c
double average(int data[], int size)
```

戻り値を `int` にすると、小数部分が失われる。

例えば、

```text
12.833333...
↓
intに変換
↓
12
```

となってしまう。

そのあと `double` 型の変数へ入れても、

```text
12
↓
12.000000
```

になるだけで、失われた小数部分は戻らない。

---

## 10. 整数の配列から平均値を求めるときの型

元のデータが整数なら、配列は `int` のままでよい。

```c
int data[6];
```

平均値を求めるためだけに配列全体を `double` にする必要はない。

例えば、

```c
double average(int data[], int size)
```

とする。

つまり、

```text
配列の型      → int
関数の引数    → int[]
平均値の戻り値 → double
```

という形にできる。

---

## 11. int同士の割り算とキャスト

以下のように、

```c
int total;
int size;
```

の場合、

```c
total / size
```

は、

```text
int ÷ int
```

になるため、小数部分が切り捨てられる。

そこで、

```c
return (double)total / size;
```

とキャストできる。

例えば、

```text
77 / 6
```

では整数同士なので、

```text
12
```

になる。

一方、

```c
(double)77 / 6
```

なら、

```text
77.0 / 6
```

として計算され、

```text
12.833333...
```

になる。

---

## 12. totalが最初からdoubleならキャストは不要

以下の場合、

```c
double total = 0;
```

`total` がすでにdouble型なので、

```c
return total / size;
```

だけで小数の計算になる。

この場合、

```c
return (double)total / size;
```

と書いても間違いではないが、すでにdoubleなのでキャストする必要はない。

---

## 13. 配列の型は関数の引数と合わせる

普通の値では、

```c
double x = 10;
```

のように `int` から `double` への自動型変換が行われる場合がある。

しかし、配列では考え方が異なる。

例えば、

```c
double data[5];
```

を、

```c
void function(int data[], int size);
```

へそのまま渡すことはできない。

関数の引数では、

```text
int[]    → int型の配列
double[] → double型の配列
```

として、基本的に型を合わせる必要がある。

---

## 14. 配列とポインタの関係への入口

関数の引数で、

```c
int data[]
```

と書いた場合、関数へ配列そのものの全情報が渡されるわけではない。

実質的には配列の先頭要素のアドレスを使って処理する。

そのため、関数側では配列の要素数が自動的には分からない。

```text
配列の場所
+
要素数
```

をセットで渡すのが基本となる。

この仕組みは、後のDay24「配列とポインタの関係」で詳しく学習する。

---

## 15. 最大値を求める

最大値を求める場合は、最初の要素を最大値候補にする。

```c
int max = data[0];
```

そして、配列の各要素と比較する。

```c
for (int i = 0; i < size; i++) {
    if (max < data[i]) {
        max = data[i];
    }
}
```

より大きい値を発見したら、その値を新しい最大値として保存する。

---

## 16. 最大値の初期値を0にしない理由

以下のように、

```c
int max = 0;
```

としてしまうと、すべて負の数だった場合に正しい最大値を求められない。

例えば、

```text
-5
-2
-8
```

の場合、本当の最大値は、

```text
-2
```

だが、

```c
int max = 0;
```

では0より大きい値が存在しないため、結果が0になってしまう。

そこで、

```c
int max = data[0];
```

として、実際に配列に存在する最初の値から比較を始める。

---

## 17. 最小値を求める

最小値も最大値と同じ考え方で、最初の要素を候補にする。

```c
int min = data[0];
```

そして、

```c
for (int i = 0; i < size; i++) {
    if (min > data[i]) {
        min = data[i];
    }
}
```

とする。

今の最小値より小さい値が見つかった場合、その値へ更新する。

---

## 18. 最大値と最小値の考え方

最大値：

```c
if (max < data[i]) {
    max = data[i];
}
```

意味：

```text
現在の最大値より大きい
↓
最大値を更新する
```

最小値：

```c
if (min > data[i]) {
    min = data[i];
}
```

意味：

```text
現在の最小値より小さい
↓
最小値を更新する
```

---

## 19. 変数の初期化が必要な場合

例えば、

```c
int total = 0;
```

としている理由は、その後、

```c
total = total + data[i];
```

と、現在の `total` の値を計算に使用するから。

右辺でその変数自身を使用する場合、最初の値が必要になる。

```text
total = total + data[i]
        ↑
        現在のtotalの値が必要
```

そのため、

```c
int total = 0;
```

のように初期化する。

---

## 20. 宣言だけでもよい変数

以下の場合、

```c
double answer;

answer = total / size;
```

`answer` の以前の値を計算に使用していない。

計算結果を新しく代入しているだけなので、

```c
double answer;
```

と宣言だけしておいて、あとから値を代入できる。

つまり、

```text
現在の値を使って次の値を計算する
→ 初期値が必要

あとから新しい値を代入するだけ
→ 宣言だけでもよい
```

という違いがある。

---

## 21. 不要な変数は作らず直接returnできる

以下のように、

```c
double answer;

answer = total / size;

return answer;
```

としてもよいが、`answer` を他で使用しない場合は、

```c
return total / size;
```

と直接返せる。

処理が単純な場合は、この方が短く分かりやすい。

---

## 22. 関数の戻り値と変数の型

関数が、

```c
double average(...)
```

なら、平均値を受け取る側も、

```c
double average_value;
```

などの `double` 型で受け取る。

合計・最大値・最小値が整数なら、

```c
int
```

で返せる。

例：

```text
合計値   → int
平均値   → double
最大値   → int
最小値   → int
```

---

## 23. 関数の役割を分ける

関数は、できるだけ役割を明確にする。

例えば、

```text
add()
→ 合計値を計算して返す

average()
→ 平均値を計算して返す

maximum()
→ 最大値を計算して返す

minimum()
→ 最小値を計算して返す
```

というように分ける。

計算する関数の中で表示まで行うより、

```text
関数
→ 計算して結果を返す

main
→ 結果を受け取って表示する
```

と分けることで、関数を他の処理でも使いやすくなる。

---

## 24. 変数の使い回しと可読性

同じ型の結果であれば、

```c
int answer;
```

を、

```text
合計値
↓
最大値
↓
最小値
```

のように上書きして使うこともできる。

動作上は問題ない。

ただし実務では、

```c
int total;
int max;
int min;
double average;
```

のように、役割ごとに変数を分けた方がコードを読みやすい。

基本的には、

```text
正しく動く
↓
読みやすくする
↓
必要な場合だけ最適化する
```

という考え方が重要。

小さな変数を数個減らすことよりも、コードの意味が分かりやすいことを優先する。
