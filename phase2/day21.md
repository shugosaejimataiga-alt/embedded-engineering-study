
# C-Day21 ポインタ基礎

## 学習内容

C-Day21では、C言語におけるポインタの基礎について学習した。

今回扱った内容は以下。

- メモリアドレス
- アドレス演算子 `&`
- ポインタ変数
- 間接参照演算子 `*`
- ポインタが保持しているアドレス
- ポインタが指している先の値
- `%p` によるアドレス表示
- `%d` による整数値表示

---

## 1. メモリアドレス

変数を作ると、その値はコンピュータのメモリ上に保存される。

例：

    int temperature = 25;

この場合、`25` という値はメモリ上のどこかに保存されている。

イメージ：

    メモリアドレス      保存されている値
    0x1000             25

この「メモリ上の場所を表す番号」がメモリアドレス。

つまり変数には、

- 変数名
- 値
- メモリアドレス

が存在する。

---

## 2. アドレス演算子 `&`

変数のメモリアドレスを取得するために `&` を使用する。

例：

    int temperature = 25;

この変数に対して、

    &temperature

とすると、

    temperatureが保存されているメモリアドレス

を取得できる。

整理すると、

    temperature
    → temperatureに保存されている値

    &temperature
    → temperatureのメモリアドレス

となる。

---

## 3. ポインタ変数

ポインタ変数とは、

    メモリアドレスを保存する変数

のこと。

例：

    int temperature = 25;
    int *p = &temperature;

この場合、

    temperature
    → 25

    &temperature
    → temperatureのメモリアドレス

    p
    → temperatureのメモリアドレス

となる。

つまり、

    int *p = &temperature;

は、

    temperatureのメモリアドレスを
    ポインタ変数pに保存する

という意味。

---

## 4. ポインタ変数の宣言

普通の整数型変数は、

    int number;

と宣言する。

ポインタ変数は、

    int *p;

と宣言する。

この場合、

    p
    → int型の値を指すポインタ変数

という意味になる。

---

## 5. `*` の2つの意味

`*` は使われる場所によって意味が変わる。

### ポインタ変数を宣言するとき

    int *p;

この `*` は、

    pはポインタ変数である

ことを表している。

### ポインタが指している先の値を見るとき

    *p

この `*` は、

    pに保存されているメモリアドレスが
    指している先の値

を表す。

例：

    int number = 40;
    int *p = &number;

の場合、

    number
    → 40

    &number
    → numberのメモリアドレス

    p
    → numberのメモリアドレス

    *p
    → 40

となる。

---

## 6. `*` の見分け方

同じ `*` でも、変数宣言なのか、値を取得しているのかで意味が違う。

    int *p;

これは変数宣言なので、

    ポインタ変数pを作っている

という意味。

一方、

    printf("%d\n", *p);

では、すでに存在する `p` を使用しているので、

    pが指している先の値を取得している

という意味。

基本的には、

    型名と一緒に宣言されている
    → ポインタ変数の宣言

    すでにあるポインタに対して *p と書かれている
    → 指している先の値を取得

と見分ける。

---

## 7. `&変数` と `p` の関係

例：

    int speed = 60;
    int *p = &speed;

この場合、

    &speed
    → speedのメモリアドレス

    p
    → speedのメモリアドレス

なので、

    &speed と p は同じアドレスを表す

ことになる。

---

## 8. `p` と `*p` の違い

ここは重要。

    p
    → ポインタ変数に保存されているメモリアドレス

    *p
    → そのメモリアドレスが指している先に保存されている値

例：

    int number = 80;
    int *p = &number;

なら、

    p
    → numberのメモリアドレス

    *p
    → 80

となる。

---

## 9. `%p` と `%d`

### `%d`

整数値を表示するときに使う。

例：

    printf("%d\n", number);
    printf("%d\n", *p);

`number` や `*p` が整数値なら、その値が表示される。

### `%p`

メモリアドレスを表示するときに使う。

例：

    printf("%p\n", (void *)&number);
    printf("%p\n", (void *)p);

`&number` と `p` が同じアドレスを表している場合、この2つには同じアドレスが表示される。

---

## 10. 基本コード

    #include <stdio.h>

    int main(void)
    {
        int number = 120;
        int *p = &number;

        printf("%d\n", number);
        printf("%p\n", (void *)&number);
        printf("%p\n", (void *)p);
        printf("%d\n", *p);

        return 0;
    }

それぞれの意味：

    number
    → numberに保存されている値

    &number
    → numberのメモリアドレス

    p
    → numberのメモリアドレス

    *p
    → pが指している先に保存されている値

---

## 11. メモリのイメージ

    int number = 120;
    int *p = &number;

の場合、

    number
    アドレス：0x1000
    値：120

    p
    アドレス：0x2000
    値：0x1000

のような状態になる。

つまり、

    p
    ↓
    0x1000
    ↓
    number
    ↓
    120

という関係になる。

---

## 12. 今回理解した重要な関係

    number
    → 値

    &number
    → numberのメモリアドレス

    p
    → pに保存されているメモリアドレス

    *p
    → pが指しているメモリアドレスに保存されている値

例：

    int number = 120;
    int *p = &number;

なら、

    number   → 120
    &number  → numberのメモリアドレス
    p        → numberのメモリアドレス
    *p       → 120

となる。

---

## 自分の言葉での理解

### メモリアドレスとは

変数の値が保存されているメモリ上の場所。

### `&` とは

変数に `&` を付けることで、その変数のメモリアドレスを取得できる。

    &number

なら、

    numberのメモリアドレス

を表す。

### ポインタ変数とは

メモリアドレスを保存するための変数。

    int *p = &number;

なら、

    numberのメモリアドレスをpに保存している

という意味。

### `*p` とは

ポインタ変数 `p` に保存されているメモリアドレスが指している先の値を表す。

    p
    → アドレス

    *p
    → そのアドレスに保存されている値
