# 1. for文

## for文とは

`for`文は、主に**繰り返す回数がある程度決まっている処理**で使用する。

基本構文：

```c
for (初期化; 条件式; 更新処理) {
    繰り返す処理;
}
```

例：

```c
for (int count = 1; count <= 5; count++) {
    printf("%d\n", count);
}
```

実行結果：

```text
1
2
3
4
5
```

## for文の処理の流れ

以下のコードの場合、

```c
for (int count = 1; count <= 5; count++) {
    printf("%d\n", count);
}
```

それぞれの役割は次の通り。

### 初期化

```c
int count = 1
```

ループ開始時に一度だけ実行される。

`count`を1から開始している。

### 条件式

```c
count <= 5
```

この条件が成立している間、ループを繰り返す。

### 更新処理

```c
count++
```

1回の繰り返しが終了するたびに、`count`を1増やす。

処理の流れ：

```text
count = 1
↓
count <= 5 を確認
↓
ループ内の処理
↓
count++
↓
count <= 5 を確認
↓
ループ内の処理
↓
...
```

# 2. for文で値を減らす

`for`文では、値を増やすだけではなく減らすこともできる。

例：

```c
for (int count = 5; count >= 1; count--) {
    printf("%d\n", count);
}
```

実行結果：

```text
5
4
3
2
1
```

`count--`によって、繰り返すたびに1ずつ値を減らしている。

## 2ずつ減らす

```c
for (int count = 10; count >= 2; count -= 2) {
    printf("%d\n", count);
}
```

実行結果：

```text
10
8
6
4
2
```

```c
count -= 2;
```

は、

```c
count = count - 2;
```

と同じ意味になる。

# 3. while文とfor文の違い

同じ繰り返し処理を`while`と`for`のどちらでも書ける場合がある。

## while

```c
int count = 1;

while (count <= 5) {
    printf("%d\n", count);
    count++;
}
```

## for

```c
for (int count = 1; count <= 5; count++) {
    printf("%d\n", count);
}
```

`for`文では、

- 初期化
- 条件式
- 更新処理

を1か所にまとめて記述できる。

特に、

```text
10回繰り返す
1〜100まで処理する
配列の要素を順番に処理する
```

など、繰り返す回数がある程度決まっている場合に使いやすい。

# 4. break

`break`は、**ループそのものをその時点で終了する**ために使用する。

例：

```c
for (int count = 1; count <= 10; count++) {

    if (count == 7) {
        break;
    }

    printf("%d\n", count);
}
```

実行結果：

```text
1
2
3
4
5
6
```

`count == 7`になった時点で、

```c
break;
```

が実行される。

そのためループそのものが終了し、`7`以降は処理されない。

---

# 5. continue

`continue`は、**現在の繰り返しの残りの処理だけを飛ばして、次の繰り返しへ進む**ために使用する。

例：

```c
for (int count = 1; count <= 5; count++) {

    if (count == 3) {
        continue;
    }

    printf("%d\n", count);
}
```

実行結果：

```text
1
2
4
5
```

`count == 3`のとき、

```c
continue;
```

が実行される。

そのため、その下にある`printf`は実行されず、次の繰り返しへ進む。

ループ自体は終了しない。

---

# 6. breakとcontinueの違い

重要な違い：

```text
break
→ ループそのものを終了する

continue
→ 現在の回の残りの処理だけを飛ばして、次の繰り返しへ進む
```

例：

```c
for (int count = 1; count <= 6; count++) {

    if (count == 2) {
        continue;
    }

    if (count == 5) {
        break;
    }

    printf("%d\n", count);
}
```

実行結果：

```text
1
3
4
```

処理の流れ：

```text
count = 1
→ 表示

count = 2
→ continue
→ 表示せず次へ

count = 3
→ 表示

count = 4
→ 表示

count = 5
→ break
→ ループ終了
```

# 7. 二重ループ

## 二重ループとは

**for文の中に、さらにfor文を書く処理**を二重ループという。

例：

```c
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 2; j++) {
        printf("%d %d\n", i, j);
    }
}
```

実行結果：

```text
1 1
1 2
2 1
2 2
3 1
3 2
```

外側の`for`文が1回進むごとに、内側の`for`文が最初から最後まで実行される。

処理のイメージ：

```text
i = 1
    j = 1
    j = 2

i = 2
    j = 1
    j = 2

i = 3
    j = 1
    j = 2
```

---

# 8. 二重ループとcontinue

二重ループの内側でも`continue`を使用できる。

```c
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {

        if (j == 2) {
            continue;
        }

        printf("%d %d\n", i, j);
    }
}
```

実行結果：

```text
1 1
1 3
2 1
2 3
3 1
3 3
```

`j == 2`のときだけ、その回の内側ループの残りの処理を飛ばす。

外側のループはそのまま継続する。

---

# 9. 二重ループとbreak

二重ループの内側で`break`を実行した場合、**内側のループだけが終了する**。

例：

```c
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {

        if (j == 2) {
            break;
        }

        printf("%d %d\n", i, j);
    }
}
```

実行結果：

```text
1 1
2 1
3 1
```

流れ：

```text
i = 1
    j = 1 → 表示
    j = 2 → break
    内側のループ終了

i = 2
    j = 1 → 表示
    j = 2 → break

i = 3
    j = 1 → 表示
    j = 2 → break
```

`break`が内側の`for`文にあるため、外側の`for`文まで終了するわけではない。

---

# 10. 二重ループでbreakとcontinueを組み合わせる

```c
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 5; j++) {

        if (j == 2) {
            continue;
        }

        if (j == 4) {
            break;
        }

        printf("%d %d\n", i, j);
    }
}
```

実行結果：

```text
1 1
1 3
2 1
2 3
3 1
3 3
```

処理の流れ：

```text
j = 1
→ 表示

j = 2
→ continue
→ printfを実行せず次へ

j = 3
→ 表示

j = 4
→ break
→ 内側のループ終了
```

この処理が`i = 1`、`i = 2`、`i = 3`について繰り返される。

# 11. for文内で宣言した変数の範囲

次のように、

```c
for (int j = 1; j <= 5; j++) {
    printf("%d\n", j);
}
```

`for`文の中で宣言した`j`は、その`for`文の範囲内で使用する。

そのため、次のようには書けない。

```c
for (int j = 1; j <= 5; j++) {
}

printf("%d\n", j);
```

`j`を使用する処理は、その変数を使用できる範囲を意識して記述する必要がある。

# 12. 今回注意したミス

## printfのセミコロン

誤り：

```c
printf("%d\n", count)
```

正しい：

```c
printf("%d\n", count);
```

C言語では文の最後に`;`が必要。

## continueのスペル

誤り：

```c
contnue;
```

正しい：

```c
continue;
```

## 二重ループの条件変数

内側のループで`j`を繰り返す場合、

誤り：

```c
for (int j = 1; i <= 5; j++)
```

正しい：

```c
for (int j = 1; j <= 5; j++)
```

初期化、条件式、更新処理でどの変数を操作しているか確認する。

## printfの位置

`continue`や`break`による判定後に値を表示したい場合は、

```c
if (j == 2) {
    continue;
}

if (j == 4) {
    break;
}

printf("%d %d\n", i, j);
```

のように、表示処理をループ内の適切な位置に置く。

## 改行文字

```c
printf("%d %d", i, j);
```

では、繰り返しの結果が横につながって表示される。

1回ごとに改行する場合は、

```c
printf("%d %d\n", i, j);
```

とする。

`\n`は改行を表す。

# 13. 自分の言葉での理解

## for文はどんなときに使うか

何回繰り返すかがある程度決まっているときに使用する繰り返し処理。

## breakとは

指定された条件になった時点で、そのループそのものを終了する。

例えば、

```c
if (j == 4) {
    break;
}
```

なら、`j == 4`になった時点でそのループを終了するため、それ以降の処理は行われない。

## continueとは

指定された条件の回だけ残りの処理を飛ばして、次の繰り返しへ進む。

例えば、

```c
if (j == 2) {
    continue;
}
```

なら、`j == 2`の回ではそれ以降の処理を行わず、次の`j`へ進む。

## 二重ループとは

`for`文の中に、さらに`for`文がある処理。

外側のループが1回進むごとに、内側のループが繰り返される。
