# 1. 変数

変数とは、プログラムの中で値を保存しておくための名前付きの場所。

例：

```c
int score = 80;
```

この場合、

- `int`：整数を扱うデータ型
- `score`：変数名
- `80`：保存する値

という意味になる。

イメージとしては、`score`という名前の箱を用意して、その中に`80`を入れている。

---

# 2. 変数宣言

変数を使用するためには、まず変数を宣言する。

例：

```c
int temperature;
```

これは、

「`int`型の`temperature`という変数を用意する」

という意味。

このように、変数を用意することを**変数宣言**という。

---

# 3. 代入

すでに宣言されている変数へ値を入れることを**代入**という。

例：

```c
int temperature;

temperature = 30;
```

この場合、

```c
int temperature;
```

で変数を宣言し、

```c
temperature = 30;
```

で`temperature`に`30`を代入している。

また、一度値が入っている変数へ別の値を代入することもできる。

```c
int temperature = 20;

temperature = 30;
```

この場合、最初は`20`だった`temperature`の値が`30`へ変更される。

---

# 4. 初期化

変数を宣言すると同時に最初の値を設定することを**初期化**という。

例：

```c
int number = 10;
```

これは、

- `number`という変数を宣言する
- 同時に`10`を入れる

という2つのことを行っている。

つまり、

```c
int number;
number = 10;
```

は、

「宣言したあとに代入」

であり、

```c
int number = 10;
```

は、

「宣言と同時に初期化」

である。

---

# 5. 変数宣言・初期化・代入の違い

## 変数宣言

変数を使用するための場所を用意する。

```c
int number;
```

`number`という`int`型の変数を宣言している。

この時点では、自分で値を設定していない。

ローカル変数を初期化せずに値を読み取ることは危険なので、基本的には使用前に値を設定する。

## 初期化

変数を宣言すると同時に最初の値を設定する。

```c
int number = 10;
```

`number`を宣言すると同時に`10`を設定している。

## 代入

すでに宣言されている変数へ後から値を設定する。

```c
number = 20;
```

すでに存在する`number`という変数へ`20`を代入している。

---

# 6. 定数

プログラムでは、途中で変更する値だけでなく、変更したくない値も使用する。

そのような値を定数として扱う。

例えば、センサー制御で、

- 現在の温度
- ファンをONにする基準温度

がある場合、

現在の温度は時間によって変化する。

一方、ファンをONにする基準温度は判定基準なので、途中で勝手に変更されたくない。

そのため、

```c
int temperature = 25;
const int fanOnTemperature = 30;
```

のように使い分ける。

---

# 7. const

`const`は、値を変更できないように指定するための修飾子。

例：

```c
const int limit = 50;
```

この場合、

- `const`：値を変更できないようにする修飾子
- `int`：整数型
- `limit`：変数名
- `50`：初期値

となる。

`limit`は`50`で初期化され、その後は変更できない。

例えば、

```c
const int limit = 50;

limit = 100;
```

のような変更はできない。

`const`はデータ型そのものではない。

データ型は`int`であり、`const`はその値を変更できないように指定する修飾子。

---

# 8. 変数と定数の使い分け

## 変数

あとから値が変化するものに使用する。

例：

```c
int temperature = 25;
```

現在の温度は変化するため、普通の変数として扱う。

後から、

```c
temperature = 28;
```

のように変更できる。

## 定数

プログラムの途中で変更したくない値に使用する。

例：

```c
const int limit = 30;
```

判定基準など、途中で変更しない値として扱う。

---

# 9. センサー制御を想定した例

```c
#include <stdio.h>

int main(void)
{
    int temperature = 25;
    const int limit = 30;

    temperature = 28;

    printf("%d\n", temperature);
    printf("%d\n", limit);

    return 0;
}
```

このコードでは、

```c
int temperature = 25;
```

で、現在の温度を保存する`temperature`を`25`で初期化している。

現在の温度は変化するため、

```c
temperature = 28;
```

のように後から値を変更できる。

一方、

```c
const int limit = 30;
```

は、基準値として使用する`limit`を`30`で初期化している。

`const`が付いているため、

```c
limit = 35;
```

のように後から値を変更することはできない。

---

# 10. 今日理解した重要事項

- 変数は値を保存するための名前付きの場所
- `int temperature;`のように変数を用意することを変数宣言という
- 宣言と同時に値を設定することを初期化という
- すでに宣言された変数へ後から値を設定することを代入という
- 普通の変数は後から値を変更できる
- 途中で変更したくない値には`const`を使用する
- `const`はデータ型ではなく修飾子
- `const int`の場合、データ型は`int`
- 変化する値と固定したい値を目的に応じて使い分ける
- 未初期化のローカル変数をそのまま読み取ることは避ける
