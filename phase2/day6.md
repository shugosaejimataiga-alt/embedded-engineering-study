# C-Day6 型変換とオーバーフロー

## 学習内容

C-Day6では、C言語における型変換と、データ型の範囲を超えたときに起こるオーバーフロー・アンダーフローについて学習した。

---

## 1. 暗黙的型変換

暗黙的型変換とは、データ型が異なるときに、C言語側が自動的に型を変換することである。

例：

```c
int temperature = 25;
double value = temperature;
```

`temperature` は `int` 型で、`value` は `double` 型である。

この場合、

```text
int型の25
↓
double型として扱える形へ自動変換
↓
25.0
```

という型変換が行われる。

このように、プログラマーが明示的に型変換を書かなくても、C言語が自動で変換するものを暗黙的型変換という。

---

## 2. 明示的型変換

明示的型変換とは、C言語に自動変換を任せるのではなく、プログラマー自身が「この型に変換する」と明示的に指定することである。

例：

```c
int a = 7;
int b = 2;

double result = (double)a / b;
```

`(double)a` と書くことで、`a` を `int` 型から `double` 型へ明示的に変換している。

---

## 3. キャスト

キャストとは、

```c
(変換したい型) 値
```

という形で、明示的に型変換する書き方・操作のこと。

例：

```c
(double)a
```

これは、`a` を `double` 型へ変換するキャストである。

---

## 4. int同士の割り算とキャスト

以下の場合、

```c
int a = 7;
int b = 2;

double result = a / b;
```

`a` と `b` は両方とも `int` 型なので、割り算も整数として行われる。

```text
7 / 2
↓
3
```

小数部分の `.5` はこの時点で失われる。

その後、

```text
int型の3
↓
double型へ暗黙的型変換
↓
3.0
```

となる。

つまり、

```c
double result = a / b;
```

と書いても、代入先が `double` だから自動的に小数計算になるわけではない。

計算自体は、まず演算に使われているデータ型によって行われる。

---

## 5. 小数まで計算したい場合

整数同士の割り算で小数まで必要な場合は、計算前に少なくとも片方を `double` へキャストする。

```c
int a = 7;
int b = 2;

double result = (double)a / b;
```

流れは、

```text
a
int型 7
↓
(double)a により明示的型変換
↓
double型 7.0
```

となる。

そのため計算時は、

```text
7.0 / 2
```

となり、`b` 側も計算時に自動的に `double` として扱われる。

結果、

```text
7.0 / 2.0
↓
3.5
```

となる。

両方を明示的にキャストする場合は、

```c
(double)a / (double)b
```

と書くこともできる。

ただし、小数計算をしたいだけなら片方を `double` にすれば十分である。

---

## 6. 計算前にデータ型を意識する

今回の学習で重要だったのは、

```text
計算してから型変換するのか
型変換してから計算するのか
```

という違いである。

例：

```c
double result = 7 / 2;
```

では、

```text
① 7 / 2 をint同士で計算
② 3になる
③ 3をdoubleへ暗黙的型変換
④ 3.0になる
```

一方、

```c
double result = (double)7 / 2;
```

では、

```text
① 7をdoubleへ明示的型変換
② 7.0 / 2.0として計算
③ 3.5になる
```

となる。

そのため、

```text
整数として計算したい
→ intのまま計算する

小数まで計算したい
→ 計算前にdoubleなどへ型変換する
```

という判断が必要である。

---

## 7. 整数の昇格

整数の昇格とは、`char` や `short` などの小さい整数型が、計算するときに通常 `int` 型へ自動的に変換されることである。

例：

```c
short a = 100;
short b = 200;

int result = a + b;
```

`a` と `b` は `short` 型だが、

```text
short
↓
intへ自動変換
↓
int同士で計算
```

という処理が行われる。

この自動変換を整数の昇格という。

整数の昇格は、暗黙的型変換の一種である。

---

## 8. charは文字専用ではなく整数型

`char` は主に1文字を表すときに使われるが、C言語では整数型の一種である。

例：

```c
char c = 'A';
```

文字 `'A'` も内部では対応する整数値として扱われている。

一般的なASCII環境では、

```text
'A' = 65
```

となる。

そのため、

```c
char c = 'A';
int result = c + 1;
```

のように、`char` を計算に使うこともできる。

計算時には、

```text
char型
↓
整数の昇格
↓
int型
```

となる。

つまり、`char` は文字を扱うときによく使われるが、データ型としては整数型であり、計算にも使える。

---

## 9. オーバーフロー

オーバーフローとは、データ型が表現できる上限を超えることである。

例として `uint8_t` を使った。

`uint8_t` は8bitの符号なし整数型である。

8bitなので、

```text
2^8 = 256通り
```

の組み合わせを持つ。

ただし、0から数えるため、表現できる値の範囲は、

```text
0 ～ 255
```

となる。

つまり、

```text
組み合わせ数：256通り
最大値：255
```

である。

例：

```c
uint8_t value = 255;

value = value + 1;
```

本来の計算結果は、

```text
255 + 1 = 256
```

である。

しかし `uint8_t` では `256` を表せない。

符号なし整数型では範囲を超えると巡回するため、

```text
255 + 1
↓
0
```

となる。

このように上限を超えることをオーバーフローという。

---

## 10. アンダーフロー

アンダーフローとは、データ型が表現できる下限を下回ることである。

例：

```c
uint8_t value = 0;

value = value - 1;
```

本来の計算結果は、

```text
0 - 1 = -1
```

である。

しかし `uint8_t` は `unsigned`、つまり0以上の値しか表せない。

`uint8_t` の範囲は、

```text
0 ～ 255
```

なので、下限の0を下回ると巡回して、

```text
0 - 1
↓
255
```

となる。

このように下限を下回ることをアンダーフローという。

---

## 11. 符号なし整数型の巡回

`uint8_t` のような符号なし整数型では、範囲を超えると値が巡回する。

`uint8_t` なら、

```text
0 → 1 → 2 → ... → 254 → 255 → 0
```

という輪のように考えることができる。

逆方向では、

```text
0 → 255 → 254 → 253 ...
```

となる。

そのため、

```text
255 + 1 → 0
0 - 1   → 255
```

となる。

このような巡回がC言語として保証されているのは符号なし整数型である。

符号あり整数型では、範囲を超えたときに必ず反対側へ巡回するとは保証されない。

---

## 12. オーバーフローとアンダーフローの違い

```text
オーバーフロー
→ データ型で表現できる上限を超える

アンダーフロー
→ データ型で表現できる下限を下回る
```

今回の `uint8_t` では、

```text
255 + 1 → 0
0 - 1   → 255
```

となる。

---

## 13. 暗黙的型変換と明示的型変換の違い

### 暗黙的型変換

C言語が自動的に型を変換する。

例：

```c
int number = 10;
double result = number;
```

```text
int
↓
C言語が自動変換
↓
double
```

### 明示的型変換

プログラマー自身が型を指定して変換する。

例：

```c
double result = (double)number;
```

```text
int
↓
(double) と自分で指定
↓
double
```

この明示的型変換の書き方をキャストという。

---

## 14. 整数の昇格と通常の暗黙的型変換

整数の昇格も暗黙的型変換の一種である。

例：

```c
short a = 100;
short b = 50;

int result = a + b;
```

計算するとき、

```text
short
↓
int
```

へ自動的に変換される。

このように、`char` や `short` などの小さい整数型が計算時に `int` へ自動変換されることを、特に整数の昇格という。

---

## 15. 最終確認で扱ったコード

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    int a = 9;
    int b = 2;

    double result1 = a / b;
    double result2 = (double)a / b;

    short x = 100;
    short y = 50;
    int result3 = x + y;

    uint8_t max_value = 255;
    max_value = max_value + 1;

    uint8_t min_value = 0;
    min_value = min_value - 1;

    return 0;
}
```

### result1

```c
double result1 = a / b;
```

`a` と `b` は両方とも `int` 型なので、

```text
9 / 2
↓
4
```

となる。

その後 `double` 型へ暗黙的型変換され、

```text
4.0
```

が `result1` に入る。

### result2

```c
double result2 = (double)a / b;
```

`a` を、

```c
(double)a
```

によって `int` から `double` へ明示的に型変換している。

そのため、

```text
9.0 / 2.0
↓
4.5
```

となる。

最終的に `result2` には `4.5` が入る。

### result3

```c
short x = 100;
short y = 50;

int result3 = x + y;
```

`x` と `y` は `short` 型だが、計算時に整数の昇格によって通常 `int` 型へ自動変換される。

```text
short 100
short 50
↓
intへ整数昇格
↓
100 + 50
↓
150
```

となる。

### max_value

```c
uint8_t max_value = 255;

max_value = max_value + 1;
```

`uint8_t` の範囲は、

```text
0 ～ 255
```

なので、

```text
255 + 1 = 256
```

は範囲外になる。

符号なし整数型なので巡回し、

```text
255 + 1 → 0
```

となる。

これはオーバーフローである。

### min_value

```c
uint8_t min_value = 0;

min_value = min_value - 1;
```

本来は、

```text
0 - 1 = -1
```

になる。

しかし `uint8_t` は符号なし整数型なので、負の数を表せない。

そのため巡回し、

```text
0 - 1 → 255
```

となる。

これはアンダーフローである。

## C-Day6で重要だったこと

今回最も重要だったのは、

```text
どの型で計算されるのか
```

と、

```text
そのデータ型がどこまでの値を表現できるのか
```

を意識することである。

特に、

```text
代入先がdoubleだから小数計算になる
```

とは限らない。

計算そのものが先に行われ、その計算に使われているデータ型によって結果が決まる。

そのため、

```text
整数として計算したい
→ intなどの整数型のまま計算する

小数まで必要
→ 計算前にdoubleなどへ型変換する
```

という考え方が必要になる。

また、整数型ではbit数によって表現できる値の範囲が決まるため、オーバーフローやアンダーフローを防ぐには、変数がどの範囲まで値を保持できるのかを意識する必要がある。
