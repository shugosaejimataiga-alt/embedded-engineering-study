---

# 1. if文

`if` 文は、

「もし条件が成立したら、その処理を実行する」

という条件分岐を作るために使用する。

基本形は以下。

    if (条件式) {
        条件が成立したときの処理
    }

例：

    int temperature = 32;

    if (temperature >= 30) {
        printf("FAN ON\n");
    }

この場合、

    temperature >= 30

という条件を確認する。

`temperature` が32なので、

    32 >= 30

となり、条件は成立する。

そのため、

    FAN ON

と表示される。

一方で、条件が成立しなかった場合は `{ }` の中の処理は実行されない。

例：

    int temperature = 25;

    if (temperature >= 30) {
        printf("FAN ON\n");
    }

この場合、

    25 >= 30

は成立しないため、何も表示されない。

---

# 2. 条件式

`if` 文の `()` の中には、処理を実行するかどうかを判断するための条件式を書く。

例：

    if (temperature >= 30)

Day7で学習した比較演算子を条件式で使用できる。

代表的な比較演算子：

    >   より大きい
    <   より小さい
    >=  以上
    <=  以下
    ==  等しい
    !=  等しくない

例：

    if (x == 10)

これは、

「xが10と等しい場合」

という意味。

重要なのは、

    =

と

    ==

は意味が違うこと。

    x = 10;

は代入。

    x == 10

は比較。

条件式では、値が等しいか確認するときに `==` を使用する。

---

# 3. else

`else` は、

「ifの条件が成立しなかった場合に実行する処理」

を書くために使用する。

基本形：

    if (条件式) {
        条件が成立した場合の処理
    } else {
        条件が成立しなかった場合の処理
    }

例：

    int temperature = 25;

    if (temperature >= 30) {
        printf("FAN ON\n");
    } else {
        printf("FAN OFF\n");
    }

この場合、

    25 >= 30

は成立しない。

そのため `if` 側は実行されず、

    printf("FAN OFF\n");

が実行される。

結果：

    FAN OFF

`if` と `else` を使用した場合、条件によってどちらか一方の処理が実行される。

---

# 4. else if

条件を複数段階に分けたい場合は `else if` を使用する。

基本形：

    if (条件1) {
        処理1
    } else if (条件2) {
        処理2
    } else {
        処理3
    }

例：

    int temperature = 28;

    if (temperature >= 35) {
        printf("HIGH\n");
    } else if (temperature >= 25) {
        printf("NORMAL\n");
    } else {
        printf("LOW\n");
    }

この場合、条件は上から順番に確認される。

まず、

    temperature >= 35

を確認する。

    28 >= 35

なので偽。

次に、

    temperature >= 25

を確認する。

    28 >= 25

なので真。

そのため、

    NORMAL

と表示される。

---

# 5. if / else if / else は上から順番に判定される

`if / else if / else` では、条件を上から順番に確認する。

そして、

「最初に条件が成立した場所だけ」

が実行される。

例：

    int temperature = 36;

    if (temperature >= 35) {
        printf("DANGER\n");
    } else if (temperature >= 30) {
        printf("WARNING\n");
    } else {
        printf("NORMAL\n");
    }

`temperature = 36` の場合、

    36 >= 35

が最初に成立する。

そのため、

    DANGER

が表示される。

その後の、

    temperature >= 30

は確認されない。

36は30以上でもあるが、最初の条件ですでに成立しているため。

---

# 6. 条件を書く順番の重要性

複数の範囲を判定するときは、条件を書く順番が重要。

例えば、

    if (temperature >= 35) {
        printf("DANGER\n");
    } else if (temperature >= 30) {
        printf("WARNING\n");
    } else {
        printf("NORMAL\n");
    }

とすることで、

    35以上       → DANGER
    30以上35未満 → WARNING
    30未満       → NORMAL

という分岐になる。

`else if (temperature >= 30)` では、

「30以上35未満」

と直接書いているわけではない。

先に、

    temperature >= 35

を確認しているため、その条件に当てはまらなかった値だけが次の `else if` に進む。

そのため結果的に、

    30以上35未満

という範囲になる。

---

# 7. 入れ子になった条件分岐

`if` 文の中に、さらに `if` 文を書くことができる。

これを入れ子になった条件分岐として使用できる。

例：

    int temperature = 32;
    int humidity = 70;

    if (temperature >= 30) {
        if (humidity >= 60) {
            printf("HOT AND HUMID\n");
        }
    }

処理の流れ：

    temperature >= 30
            ↓
           真
            ↓
    humidity >= 60
            ↓
           真
            ↓
    HOT AND HUMID

最初の条件、

    temperature >= 30

が成立しなければ、内側の、

    if (humidity >= 60)

は確認されない。

つまり、

    if (条件A) {
        if (条件B) {
            処理
        }
    }

は、

「条件Aが成立していて、さらに条件Bも成立している場合」

に処理を実行する構造になる。

---

# 8. 入れ子のif文とelse

入れ子になった `if` の中でも `else` を使用できる。

例：

    int mode = 1;
    int temperature = 28;

    if (mode == 1) {

        if (temperature >= 30) {
            printf("FAN ON\n");
        } else {
            printf("FAN OFF\n");
        }

    } else {
        printf("STOP\n");
    }

この場合、まず、

    mode == 1

を確認する。

`mode = 1` なので真。

その後、

    temperature >= 30

を確認する。

`temperature = 28` なので偽。

そのため、

    FAN OFF

と表示される。

もし `mode == 1` が成立しなければ、温度の確認自体を行わず、

    STOP

と表示される。

---

# 9. 複数条件を段階的に判定する考え方

今回の最終問題では、

まず大きな条件を判定し、その中でさらに細かい条件を判定する考え方を学習した。

例：

    int temperature = 32;
    int humidity = 75;

    if (temperature >= 35) {

        printf("DANGER");

    } else if (temperature >= 30) {

        if (humidity >= 70) {
            printf("HOT AND HUMID");
        } else {
            printf("HOT");
        }

    } else {

        printf("NORMAL");
    }

処理の考え方：

    温度が35以上
        ↓
    DANGER

35未満なら次へ進む。

    温度が30以上
        ↓
    湿度を確認

さらに、

    湿度が70以上
        ↓
    HOT AND HUMID

湿度が70未満なら、

    HOT

温度が30未満なら、

    NORMAL

となる。

このように、

「まず大きな状態を分ける」

↓

「必要な場合だけさらに細かく分ける」

という構造を作れる。

# 10. 今回理解したif文の基本構造

## ifのみ

    if (条件) {
        処理
    }

条件が成立した場合のみ処理する。

---

## if / else

    if (条件) {
        処理A
    } else {
        処理B
    }

条件が成立した場合と成立しなかった場合で処理を分ける。

---

## if / else if / else

    if (条件1) {
        処理A
    } else if (条件2) {
        処理B
    } else {
        処理C
    }

複数の状態に処理を分ける。

---

## 入れ子のif

    if (条件1) {

        if (条件2) {
            処理
        }

    }

条件1が成立した場合だけ、さらに条件2を確認する。

# 11. 今回のミスと学んだこと

今回の演習では、条件分岐の考え方自体は正しく理解できていた。

主なミスは以下。

## セミコロンの付け忘れ

最初の演習で、

    printf("WARNING")

としてしまった。

正しくは、

    printf("WARNING");

C言語では、基本的に文の終わりに `;` が必要。

---

## 変数名のスペル違い

最終問題で、

    int humudity = 75;

と宣言した後に、

    if (humidity >= 70)

と書いてしまった。

C言語では、

    humudity
    humidity

は完全に別の変数名として扱われる。

そのため、変数名は宣言時と使用時で完全に一致させる必要がある。

修正：

    int humidity = 75;

# 13. 自分の言葉での理解

`if` 文は、条件によってプログラムの処理を変えるための仕組み。

    if (条件)

の条件が成立した場合だけ、その中の処理が実行される。

条件が成立しなかった場合の処理を書きたいときは `else` を使う。

さらに複数の状態に分けたいときは `else if` を使う。

    if
    else if
    else

では条件を上から順番に確認し、最初に成立した部分だけが実行される。

そのため、温度などを段階的に判定するときは、大きい値から順番に条件を書くことで、

    35以上
    30以上35未満
    30未満

のように範囲を分けることができる。

また、`if` の中に別の `if` を書くことで、

「ある条件が成立した場合だけ、さらに別の条件を確認する」

という処理も作れる。

例えば、

    自動モードの場合だけ温度を確認する
    温度が高い場合だけ湿度も確認する

といった段階的な制御ができる。
