# 1. 配列とは

配列とは、**同じデータ型の複数の値をまとめて管理する仕組み**。

通常、複数の値を保存する場合は、

```c
int temperature1 = 20;
int temperature2 = 25;
int temperature3 = 30;
```

のように複数の変数を用意する必要がある。

配列を使うと、

```c
int temperature[3] = {20, 25, 30};
```

のように、複数の値を1つの名前でまとめて管理できる。

イメージ：

```text
temperature[0] → 20
temperature[1] → 25
temperature[2] → 30
```

---

# 2. 配列の宣言

配列の基本的な宣言方法：

```c
データ型 配列名[要素数];
```

例：

```c
int temperature[3];
```

これは、

- データ型：int
- 配列名：temperature
- 要素数：3

という配列を作っている。

つまり、int型の値を3個保存できる。

---

# 3. 配列の初期化

配列を作ると同時に値を入れることができる。

```c
int temperature[3] = {20, 25, 30};
```

それぞれの値は、

```text
temperature[0] → 20
temperature[1] → 25
temperature[2] → 30
```

として保存される。

---

# 4. 添字（インデックス）

配列の各要素を指定するために使う番号を「添字（インデックス）」という。

C言語では、**添字は0から始まる**。

要素数が3個の場合、

```text
0
1
2
```

が使用できる添字になる。

例：

```c
int number[3] = {10, 20, 30};

printf("%d\n", number[0]);
printf("%d\n", number[1]);
printf("%d\n", number[2]);
```

出力：

```text
10
20
30
```

重要：

```text
要素数3個
↓
使用できる添字
0～2
```

---

# 5. 配列の値を変更する

配列の値は、添字を指定して後から変更できる。

例：

```c
int score[4] = {60, 70, 80, 90};

score[2] = 85;
```

変更後：

```text
score[0] → 60
score[1] → 70
score[2] → 85
score[3] → 90
```

`score[2]` は3番目の要素。

配列は0から数えるため、

```text
1番目 → [0]
2番目 → [1]
3番目 → [2]
4番目 → [3]
```

となる。

---

# 6. 配列とfor文

配列はfor文と非常に相性が良い。

例：

```c
#include <stdio.h>

int main(void)
{
    int number[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("%d\n", number[i]);
    }

    return 0;
}
```

`i` は、

```text
0
1
2
3
4
```

と変化する。

そのため、

```c
number[i]
```

は順番に、

```text
number[0]
number[1]
number[2]
number[3]
number[4]
```

となる。

結果として、配列のすべての要素を順番に処理できる。

---

# 7. for文の条件に注意する

要素数が5個の配列では、

```text
使用できる添字
0～4
```

となる。

そのため、

```c
for (int i = 0; i < 5; i++)
```

と書けばよい。

また、

```c
for (int i = 0; i <= 4; i++)
```

でも同じ範囲になる。

一方、

```c
for (int i = 0; i <= 5; i++)
```

とすると、

```text
0
1
2
3
4
5
```

まで実行されてしまう。

最後に、

```c
number[5]
```

へアクセスすることになり、配列の範囲外アクセスになる。

---

# 8. 配列の要素数と添字の関係

配列の要素数が `N` 個の場合、

```text
使用できる添字
0 ～ N - 1
```

となる。

例：

```c
int value[6];
```

の場合、

```text
要素数：6

使用できる添字：
0
1
2
3
4
5
```

つまり、

```text
0～5
```

まで使用できる。

---

# 9. 配列の範囲外アクセス

例えば、

```c
int value[6] = {5, 10, 15, 20, 25, 30};
```

の場合、

```text
value[0]
value[1]
value[2]
value[3]
value[4]
value[5]
```

までが有効。

```c
value[6]
```

は存在しない。

このように、配列として確保されていない場所へアクセスすることを「範囲外アクセス」という。

---

# 10. 範囲外アクセスが危険な理由

C言語では、配列の範囲外へアクセスしても、必ずエラーになって停止するとは限らない。

例えば、

```c
value[6]
```

のように存在しない要素へアクセスすると、

- 関係ないメモリを読み込む
- 関係ないメモリを書き換える
- 意味不明な値が出る
- プログラムが正常に動かなくなる
- 実行中に異常終了する

など、予期しない動作が起こる可能性がある。

そのため、配列を扱うときは必ず、

```text
0 ～ 要素数 - 1
```

の範囲内でアクセスする。

---

# 11. 値を変更してからfor文で表示する

配列の一部を書き換えて、その後for文で表示することもできる。

```c
#include <stdio.h>

int main(void)
{
    int temperature[5] = {22, 25, 19, 27, 24};

    temperature[2] = 21;

    for (int i = 0; i < 5; i++) {
        printf("%d\n", temperature[i]);
    }

    return 0;
}
```

処理の流れ：

```text
初期状態

temperature[0] → 22
temperature[1] → 25
temperature[2] → 19
temperature[3] → 27
temperature[4] → 24
```

↓

```c
temperature[2] = 21;
```

↓

```text
変更後

temperature[0] → 22
temperature[1] → 25
temperature[2] → 21
temperature[3] → 27
temperature[4] → 24
```

↓

for文で順番に表示する。

出力：

```text
22
25
21
27
24
```

# 今日の重要ポイント

## 配列

同じデータ型の複数の値をまとめて保存できる。

```c
int number[5] = {10, 20, 30, 40, 50};
```

## 添字は0から始まる

要素数5個なら、

```text
number[0]
number[1]
number[2]
number[3]
number[4]
```

となる。

## 要素数と最大添字

```text
最大添字 = 要素数 - 1
```

例えば、

```c
int number[5];
```

なら、

```text
要素数：5
最小添字：0
最大添字：4
```

となる。

## 値の変更

```c
number[2] = 100;
```

のように、添字を指定して値を変更できる。

## 配列とfor文

```c
for (int i = 0; i < 5; i++) {
    printf("%d\n", number[i]);
}
```

のように、添字をfor文で変化させることで配列を順番に処理できる。

## 範囲外アクセス

要素数5個なら、

```text
0～4
```

だけが有効。

```c
number[5]
```

は範囲外アクセスになる。

範囲外アクセスをすると、関係ないメモリを読み込んだり書き換えたりするなど、予期しない動作をする可能性がある。

# 自分の言葉での理解

同じデータ型の複数の値を、1つの名前でまとめて保存する仕組み。

## 添字とは何か

C言語では0から始まる。

## 配列とfor文を組み合わせる理由

## 範囲外アクセスが危険な理由

配列として確保されていない場所へアクセスすることになり、関係ないメモリを読み込んだり書き換えたりして、予期しない動作をする可能性があるから。
