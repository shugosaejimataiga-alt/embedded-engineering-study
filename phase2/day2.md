## 今日学んだ内容

### 1. main関数

C言語のプログラムは、基本的に `main` 関数から実行が始まる。

```c
int main(void)
{
    // 処理
}
```

`main` 関数の中に書かれた文が、基本的に上から順番に実行される。

例えば、

```c
int main(void)
{
    printf("Hello\n");

    return 0;
}
```

では、

```text
main関数から実行開始
↓
printfを実行
↓
Helloを表示
↓
return 0;
↓
main関数終了
↓
プログラム終了
```

という流れになる。

---

### 2. `int main(void)` の意味

```c
int main(void)
```

は、3つに分けて考えられる。

- `int`
- `main`
- `(void)`

#### `int`

この関数が最後に整数型の値を返すことを表す。

そのため、`main` 関数の最後には次のように書ける。

```c
return 0;
```

この `0` は整数なので、`int` と対応している。

#### `main`

関数の名前。

Cプログラムでは、基本的にこの `main` 関数から実行が始まる。

#### `(void)`

この `main` 関数が引数を受け取らないことを表す。

つまり、

```c
int main(void)
```

は、

「引数を受け取らず、最後に整数を返す `main` という関数」

という意味になる。

---

### 3. 文

C言語では、処理を表す1つ1つの記述を「文」と呼ぶ。

例えば、

```c
printf("Hello\n");
return 0;
```

には2つの文がある。

```c
printf("Hello\n");
```

は文字を表示する文。

```c
return 0;
```

は `main` 関数を終了して値を返す文。

---

### 4. セミコロン `;`

C言語では、多くの文の最後にセミコロンを書く。

```c
printf("Hello\n");
```

```c
return 0;
```

セミコロン `;` は、

「文の終わり」

を表す。

---

### 5. コメント

コメントは、人間がコードの内容を理解しやすくするために書く説明。

コメントとして書かれた部分は、プログラムの処理として実行されない。

#### 1行コメント

```c
// Helloを表示する
printf("Hello\n");
```

`//` からその行の最後までがコメントになる。

#### 複数行コメント

```c
/*
ここはコメント
ここもコメント
*/
```

`/*` から `*/` までがコメントになる。

---

### 6. `printf`

`printf` は、文字や数値などを画面へ表示するための関数。

例えば、

```c
printf("Hello");
```

を実行すると、

```text
Hello
```

と表示される。

---

### 7. 改行文字 `\n`

文字列の中に、

```c
\n
```

を書くと改行できる。

例えば、

```c
printf("Apple\n");
printf("Orange\n");
printf("Banana");
```

を実行すると、

```text
Apple
Orange
Banana
```

と表示される。

一方で、

```c
printf("A");
printf("B");
```

のように `\n` を書かなければ、

```text
AB
```

と同じ行に続けて表示される。

---

### 8. `printf` で整数を表示する

整数を表示するときは、`%d` を使える。

```c
printf("%d\n", 10);
```

この場合、

```text
10
```

と表示される。

`%d` は、

「ここに整数を表示する」

という場所を表す。

例えば、

```c
printf("%d\n", 42);
```

なら、

```text
42
```

と表示される。

---

### 9. `return 0;`

```c
return 0;
```

は、

「`main` 関数を終了し、正常に終了したことを示す整数 `0` を返す」

という意味。

`main` 関数は、

```c
int main(void)
```

と書かれているため、整数を返す。

その整数として `0` を返している。

---

### 10. `#include <stdio.h>`

```c
#include <stdio.h>
```

は、`printf` などの標準入出力に関する宣言を取り込むために使う。

`stdio.h` には、`printf` などの関数に関する情報が書かれている。

`#include` は、

「指定したファイルの内容を、コンパイル前に取り込む」

という処理。

イメージは次の通り。

```text
自分のCファイル
↓
#include <stdio.h>
↓
コンパイル前にstdio.hの内容を取り込む
↓
printfなどの宣言が見える状態になる
↓
GCCがコンパイルする
```

これは、OSが実行時にプログラムをメモリへ読み込む処理とは別。

```text
#include
→ コンパイル前の処理

OSが実行ファイルをメモリへ読み込む
→ プログラム実行時の処理
```

## 今日書けるようになった基本形

```c
#include <stdio.h>

int main(void)
{
    printf("Hello\n");

    return 0;
}
```

このコードについて、それぞれ次のように説明できる。

```c
#include <stdio.h>
```

`printf` などを使うために、`stdio.h` に書かれている宣言をコンパイル前に取り込む。

```c
int main(void)
```

引数を受け取らず、整数を返す `main` 関数。

プログラムは基本的にここから実行が始まる。

```c
printf("Hello\n");
```

`Hello` と表示し、その後に改行する。

```c
return 0;
```

`main` 関数を終了し、正常終了を示す整数 `0` を返す。
