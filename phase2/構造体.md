# C言語｜構造体・ポインタ・配列の表記まとめ

## 1. 前提コード

    struct Device {
        int number;
        int values[3];
    };

    struct Device device = {1, {10, 20, 30}};
    struct Device *p = &device;

- number：int型のメンバー
- values：int型の配列メンバー
- device：構造体そのもの
- p：deviceのアドレスを保持する構造体ポインタ

---

## 2. 基本ルール：. と ->

構造体のメンバーにアクセスする方法は2種類。

| 左側の式 | 使用する記号 |
|---|---|
| 構造体そのもの | . |
| 構造体を指すポインタ | -> |

例：

    device.number
    p->number
    (*p).number

この3つは、すべて同じnumberメンバーを表す。

重要：
- pは構造体を指すポインタ
- *pは構造体そのもの
- p->number と (*p).number は同じ意味
- ->は、ポインタが指す構造体のメンバーにアクセスする演算子

---

## 3. 普通のメンバー（int型）の表記

| 構造体から | ポインタから | 意味 |
|---|---|---|
| device.number | p->number | numberの値 |
| &device.number | &p->number | numberのアドレス |

例：

    device.number       // 値：1
    p->number           // 値：1

    &device.number      // numberのアドレス
    &p->number          // numberのアドレス

値を変更する場合：

    device.number = 5;
    p->number = 5;

どちらも元のdevice.numberを変更する。

---

## 4. 配列メンバーの表記

| 構造体から | ポインタから | 意味 |
|---|---|---|
| device.values | p->values | 通常、先頭要素のアドレスに変換 |
| device.values[0] | p->values[0] | 1番目の値 |
| device.values[1] | p->values[1] | 2番目の値 |
| &device.values[0] | &p->values[0] | 先頭要素のアドレス |
| &device.values[1] | &p->values[1] | 2番目の要素のアドレス |
| &device.values | &p->values | 配列全体のアドレス |

例：

    device.values       // 通常、先頭要素のアドレスに変換
    p->values           // 通常、先頭要素のアドレスに変換

    device.values[1]    // 値：20
    p->values[1]        // 値：20

    &device.values[1]   // 値20がある場所のアドレス
    &p->values[1]       // 同じアドレス

重要：
- 配列名は、通常の式では先頭要素のアドレスに変換される
- [n]を付けるとn番目の要素を表す
- &を付けると指定した対象のアドレスを取得する
- &device.valuesは配列全体のアドレス
- &device.values[0]は先頭要素のアドレス
- この2つは同じ位置を示すが、ポインタの型が異なる

---

## 5. 構造体そのものが配列の場合

前提コード：

    struct Vehicle {
        int remaining;
        float speed;
    };

    struct Vehicle vehicles[3] = {
        {80, 1.5f},
        {50, 1.0f},
        {20, 0.5f}
    };

    struct Vehicle *q = vehicles;

### 構造体とアドレスの区別

| 書き方 | 意味 |
|---|---|
| vehicles[1] | 2番目の構造体そのもの |
| &vehicles[1] | 2番目の構造体のアドレス |
| vehicles | 通常、先頭の構造体のアドレスに変換 |
| &vehicles | 構造体配列全体のアドレス |
| q | 先頭の構造体を指すポインタ |
| q[1] | 2番目の構造体そのもの |
| q + 1 | 2番目の構造体を指すポインタ |
| &q[1] | 2番目の構造体のアドレス |

### メンバーへのアクセス

| 書き方 | 意味 |
|---|---|
| vehicles[1].remaining | 2番目の構造体のremaining |
| q[1].remaining | 同じremaining |
| (q + 1)->remaining | 同じremaining |
| (&q[1])->remaining | 同じremaining |
| &q[1].remaining | remainingメンバーのアドレス |

重要：
- qは構造体ポインタ
- q[1]は構造体そのもの
- q + 1は構造体ポインタ
- q[1] と *(q + 1) は同じ意味
- q + 1 と &q[1] は同じアドレスを表す

---

## 6. 関数に構造体を渡す場合

### 構造体1個

    void checkDevice(struct Device *p);

    checkDevice(&device);

- deviceは構造体そのもの
- &deviceは構造体のアドレス
- 関数側ではp->numberなどでアクセスする

### 構造体配列

    void checkVehicles(struct Vehicle *p, int count);

    checkVehicles(vehicles, 3);

- vehiclesは配列名
- 関数に渡すと先頭要素のアドレスに変換される
- countは要素数
- 関数側ではp[i].remainingなどでアクセスする

関数の仮引数では、次の2つは同じ意味。

    struct Vehicle *p
    struct Vehicle p[]

---

## 7. 最重要ルール

① 構造体のメンバーにアクセスする

    構造体そのもの → .
    構造体ポインタ → ->

② メンバーの種類を確認する

    int型などの通常のメンバー
      → メンバーそのものを表す

    配列型のメンバー
      → 通常の式では先頭要素のアドレスに変換される

③ 値とメモリアドレスを区別する

    device.number       // メンバーの値
    &device.number      // メンバーのアドレス

    device.values[1]    // 配列の2番目の値
    &device.values[1]   // 配列の2番目のアドレス

④ ポインタそのものと、指す先を区別する

    p             // ポインタに保存されたアドレス
    *p            // ポインタが指す構造体そのもの
    &p            // ポインタ変数p自身のアドレス

    p->number     // 指している構造体のnumber
    &p->number    // numberメンバーのアドレス

⑤ 配列の添字は0から始まる

    [0] → 1番目
    [1] → 2番目
    [2] → 3番目

※配列からポインタへの自動変換には例外がある。
  代表例はsizeofや単項&を使用する場合。

---

## 8. まとめ

構造体の表記は、次の順番で判断する。

1. アクセスする対象は構造体そのものか、構造体ポインタか
2. 構造体そのものなら . 、ポインタなら ->
3. メンバーは通常の変数か、配列か
4. 値を扱うのか、アドレスを取得するのか
5. アドレスが必要なら、対象に&を付ける

この順番で判断すれば、構造体が1個でも、
構造体配列でも、構造体の中に配列がある場合でも、
同じ基本ルールを適用できる。
