# 1. while文

## 基本構文

```c
while (条件式) {
    処理;
}
```

`while`文は、条件式が真である間、処理を繰り返す。

例：

```c
#include <stdio.h>

int main(void)
{
    int number = 1;

    while (number <= 5) {
        printf("%d\n", number);
        number++;
    }

    return 0;
}
```

実行結果：

```text
1
2
3
4
5
```

---

## while文の処理順

while文は以下の順番で処理される。

```text
1. 条件式を確認する
↓
2. 条件式が真なら処理を実行する
↓
3. 変数などを更新する
↓
4. 再び条件式を確認する
↓
5. 条件式が偽になるまで繰り返す
```

例：

```c
int number = 2;

while (number < 10) {
    printf("%d\n", number);
    number += 2;
}
```

処理の流れ：

```text
number = 2

2 < 10
→ 真
→ 2を表示
→ number = 4

4 < 10
→ 真
→ 4を表示
→ number = 6

6 < 10
→ 真
→ 6を表示
→ number = 8

8 < 10
→ 真
→ 8を表示
→ number = 10

10 < 10
→ 偽
→ while文終了
```

実行結果：

```text
2
4
6
8
```

while文終了時の`number`の値は`10`になる。

ここで、

```text
最後に表示される値
```

と

```text
while文終了時の変数の値
```

は別で考える必要があることを学んだ。

# 2. ループ内での変数更新

while文では、条件式だけでなく、ループを終了させるための変数更新が重要になる。

例：

```c
int count = 1;

while (count <= 3) {
    printf("%d\n", count);
    count++;
}
```

`count++`によって、

```text
1 → 2 → 3 → 4
```

と変化する。

`count`が`4`になると、

```c
count <= 3
```

が偽になるため、while文が終了する。

---

## 減らしながら繰り返す場合

```c
int number = 10;

while (number >= 2) {
    printf("%d\n", number);
    number -= 2;
}
```

変数の変化：

```text
10 → 8 → 6 → 4 → 2 → 0
```

実行結果：

```text
10
8
6
4
2
```

`number`が`0`になると、

```c
number >= 2
```

が偽になるため終了する。

---

# 3. do-while文

## 基本構文

```c
do {
    処理;
} while (条件式);
```

`do-while`文は、最初に処理を実行してから条件式を確認する。

例：

```c
#include <stdio.h>

int main(void)
{
    int number = 3;

    do {
        printf("%d\n", number);
        number--;
    } while (number > 0);

    return 0;
}
```

実行結果：

```text
3
2
1
```

---

# 4. while文とdo-while文の違い

## while文

```c
while (条件式) {
    処理;
}
```

処理順：

```text
条件確認
↓
処理
↓
条件確認
↓
処理
```

最初の条件式が偽の場合、処理は一度も実行されない。

---

## do-while文

```c
do {
    処理;
} while (条件式);
```

処理順：

```text
処理
↓
条件確認
↓
処理
↓
条件確認
```

最初に処理を実行してから条件を確認するため、条件式が最初から偽でも最低1回は処理される。

例：

```c
int number = 10;

do {
    printf("%d\n", number);
} while (number <= 5);
```

`number <= 5`は偽だが、条件を確認する前に処理されるため、

```text
10
```

が1回表示される。

# 5. 無限ループ

無限ループとは、ループの終了条件が成立せず、処理が永遠に繰り返される状態。

例：

```c
int count = 1;

while (count <= 3) {
    printf("%d\n", count);
}
```

このコードでは、`count`の値を変更する処理がない。

そのため、

```c
count <= 3
```

は常に真になる。

`count`はずっと`1`なので、ループが終了しない。

---

## 無限ループを防ぐ考え方

while文を書くときは、以下の2点を確認する。

```text
・条件式がいつか偽になるか
・条件式を偽にするために変数が変化しているか
```

例：

```c
while (count <= 3) {
    printf("%d\n", count);
    count++;
}
```

`count++`があることで、最終的に条件式が偽になる。

---

# 6. 意図的な無限ループ

無限ループは必ずしも間違いではなく、意図的に使用する場合もある。

例：

```c
while (1) {
    printf("RUNNING\n");
}
```

C言語では`1`は真として扱われるため、

```c
while (1)
```

は常に条件が成立する。

そのため、明示的に終了させない限り処理を繰り返し続ける。

組み込みプログラムでは、マイコンを動作させ続けるために無限ループを使用することがある。

---

# 7. 式を書くだけでは変数は変更されない

今回の学習で、

```c
count + 1;
```

と

```c
count += 1;
```

の違いも確認した。

```c
count + 1;
```

では計算結果をどこにも保存していないため、`count`の値は変更されない。

変数の値を実際に変更する場合は、

```c
count = count + 1;
```

または、

```c
count += 1;
```

または、

```c
count++;
```

のように書く必要がある。

---

# 8. 複数のループで同じ変数を使用する場合

例：

```c
int count = 5;

while (count >= 1) {
    printf("%d\n", count);
    count--;
}
```

このwhile文が終了した時点では、

```text
count = 0
```

になっている。

その後、別のループで`1`から使用したい場合は、値を変更する必要がある。

例：

```c
count += 1;
```

今回の最終課題では以下のように使用した。

```c
#include <stdio.h>

int main(void)
{
    int count = 5;

    while (count >= 1) {
        printf("%d\n", count);
        count--;
    }

    count += 1;

    do {
        printf("%d\n", count);
        count++;
    } while (count <= 3);

    return 0;
}
```

実行結果：

```text
5
4
3
2
1
1
2
3
```

# 今日理解した重要ポイント

## while文

```text
条件式を最初に確認する。
条件が真である間、処理を繰り返す。
```

## do-while文

```text
最初に処理を1回実行する。
その後に条件式を確認する。
そのため最低1回は実行される。
```

## ループの終了

```text
条件式が偽になった時点で終了する。
```

## 無限ループ

```text
条件式が常に真のままになると、ループが終了しない。
```

## 変数更新

```text
ループを終了させるには、
条件式に使用している変数が適切に変化する必要がある。
```
