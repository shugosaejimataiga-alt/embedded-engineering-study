

# C言語学習記録 Day23：ポインタと関数

## 今日の学習内容

Day23では、ポインタを関数の引数として渡し、関数から呼び出し元の変数を変更する方法を学習した。

主に以下を学習した。

- 値渡し
- ポインタを引数として渡す方法
- 関数から呼び出し元の変数を変更する方法
- 出力引数
- 値渡しとポインタを渡す処理の違い
- 関数の戻り値と引数の型の見方

---

## 1. 値渡し

通常の変数を関数へ渡すと、変数そのものではなく、その値のコピーが関数へ渡される。

例：

    void changeNumber(int n)
    {
        n = 100;
    }

呼び出し側：

    int number = 25;

    changeNumber(number);

この場合、関数へ渡されるのは `number` 自体ではなく、値 `25` のコピー。

処理のイメージ：

    number = 25

        ↓ 値をコピー

    n = 25

関数内で、

    n = 100;

としても、

    number = 25
    n      = 100

となる。

`number` と `n` は別の変数なので、元の `number` は変更されない。

つまり、

    changeNumber(number);

のように普通の変数を渡す場合は値渡しになる。

---

## 2. returnを使って値を返す場合

値渡しでも、関数から `return` した値を呼び出し元で受け取れば、変数を更新できる。

例：

    int changeNumber(int n)
    {
        n = 100;
        return n;
    }

呼び出し側：

    number = changeNumber(number);

処理の流れ：

    number = 25

        ↓

    25をnへコピー

        ↓

    n = 100

        ↓

    return 100

        ↓

    100をnumberへ代入

        ↓

    number = 100

ただし、

    changeNumber(number);

だけでは、戻り値を受け取っていないため `number` は変更されない。

### 覚えたこと

`return` は値を関数の外へ返す。

そして、

    number = changeNumber(number);

のように、返された値を受け取る必要がある。

---

## 3. ポインタを関数へ渡す

ポインタを使うと、`return` を使わなくても関数から呼び出し元の変数を変更できる。

例：

    void changeNumber(int *p)
    {
        *p = 100;
    }

呼び出し側：

    int number = 25;

    changeNumber(&number);

`&number` は `number` のメモリアドレスを表す。

そのアドレスを、

    int *p

というポインタ変数で受け取る。

---

## 4. ポインタでもコピーは行われる

関数の引数は値渡しなので、ポインタを渡した場合でもコピーは行われる。

ただし、コピーされるものが普通の数値ではなく「メモリアドレス」になる。

例えば `number` が、

    number
    値       : 25
    アドレス : 0x1000

だったとする。

    changeNumber(&number);

とすると、

    &number = 0x1000

というアドレスが `p` にコピーされる。

    number
    値       : 25
    アドレス : 0x1000

    p
    値       : 0x1000

`p` と `number` は別の変数だが、`p` は `number` が存在する場所を知っている。

---

## 5. p と *p の違い

ポインタでは `p` と `*p` を区別することが重要。

    p
    → メモリアドレスを保存している

    *p
    → pが指している場所にある値

例えば、

    *p = 100;

は、

    pが持っているアドレスの場所へ行き、
    その場所に保存されている値を100にする

という意味。

そのため、

    *p = 100;

を実行すると、元の変数が、

    number = 100

に変わる。

一方、`p` が保持しているアドレス自体は変わらない。

---

## 6. * は使われる場所によって意味が違う

今回特に重要だった部分。

### 宣言で使う *

    int *p;

これは、

    pはint型の値を指すポインタ変数

という意味。

関数の引数でも同じ。

    void changeNumber(int *p)

この中の、

    int *p

もポインタ変数 `p` の宣言。

関数の `()` の中も、引数として使用する変数の宣言になっている。

例えば、

    void func(int n)

の、

    int n

も変数宣言。

同様に、

    void func(int *p)

の、

    int *p

もポインタ変数の宣言。

### 処理で使う *

    *p = 100;

の場合は、

    pが指している先の値

という意味。

### 整理

宣言の場合：

    int *p;

    → pはポインタ変数

処理の場合：

    *p = 100;

    → pが指している場所の値を変更する

---

## 7. void changeNumber(int *p) の意味

    void changeNumber(int *p)

を分解すると、

    void
    → 戻り値なし

    changeNumber
    → 関数名

    int *p
    → int型の値を指すポインタを引数として受け取る

つまり、

    void changeNumber(int *p)

は、

    int型の変数のアドレスを受け取り、
    戻り値は返さない関数

という意味。

---

## 8. 関数の戻り値と引数

例えば、

    int main(void)

では、

    int
    → 戻り値の型

    main
    → 関数名

    (void)
    → 引数なし

という意味。

つまり、

    int main(void)

は、

    引数を受け取らず、
    int型の値を返す関数

ということ。

そのため最後に、

    return 0;

を書く。

覚え方：

    戻る ← 関数名 → 入る

    int    main    (void)

---

## 9. 関数宣言の見方

### 引数なし・intを返す

    int func(void);

    戻り値：int
    引数：なし

### 引数なし・戻り値なし

    void func(void);

    戻り値：なし
    引数：なし

### intを受け取り、intを返す

    int func(int n);

    戻り値：int
    引数：int

### int型のポインタを受け取り、戻り値なし

    void func(int *p);

    戻り値：なし
    引数：int型のポインタ

---

## 10. ポインタを使って呼び出し元の変数を変更する

基本形：

    void setValue(int *p);

    int main(void)
    {
        int value = 10;

        setValue(&value);

        return 0;
    }

    void setValue(int *p)
    {
        *p = 20;
    }

処理の対応関係：

    &value
    → valueのアドレスを取得する

    setValue(&value)
    → valueのアドレスを関数へ渡す

    int *p
    → valueのアドレスを受け取るポインタを宣言する

    *p
    → valueがある場所の値へアクセスする

    *p = 20
    → valueを20へ変更する

---

## 11. 複数の値を関数から変更する

1つの関数で複数の変数を変更したい場合は、複数のポインタを引数として受け取ることができる。

例：

    void setRange(int *p1, int *p2)
    {
        *p1 = 10;
        *p2 = 100;
    }

呼び出し側：

    int min = 0;
    int max = 0;

    setRange(&min, &max);

処理：

    &min
    → minのアドレス

    &max
    → maxのアドレス

    p1
    → minのアドレスを受け取る

    p2
    → maxのアドレスを受け取る

    *p1 = 10
    → minを10に変更

    *p2 = 100
    → maxを100に変更

このように、ポインタを利用して関数から値を書き込むための引数を「出力引数」として使うことができる。

---

## 12. p = 10 と *p = 10 の違い

ここも重要。

    p = 10;

と、

    *p = 10;

は全く違う。

### p = 10

`p` はメモリアドレスを保持するポインタ変数。

そのため、

    p = 10;

は元の変数の値を10にする処理ではない。

### *p = 10

    *p = 10;

は、

    pが指している場所に10を書き込む

という意味。

元の変数を変更したい場合はこちらを使う。

---

## 13. 値渡しとポインタ渡しを同時に使う

1つの関数で、

- 読み取るための値
- 関数から変更したい値

を分けることができる。

例：

    void controlFan(int temperature, int *p);

ここでは、

    temperature
    → 普通の値渡し

    p
    → ポインタ

となる。

呼び出し側：

    controlFan(temperature, &fan);

### temperature

    temperature

は値のコピーが渡される。

関数内で `temperature` を変更しても、`main` 側の `temperature` は変更されない。

### fan

    &fan

で `fan` のアドレスを渡す。

関数内で、

    *p = 1;

などとすることで、`main` 側の `fan` を変更できる。

---

## 14. 値渡しとポインタを渡す処理の違い

### 値渡し

関数：

    void func(int n)

呼び出し：

    func(number);

処理：

    numberの値
        ↓
      コピー
        ↓
        n

`n` を変更しても元の `number` は変更されない。

---

### ポインタを渡す

関数：

    void func(int *p)

呼び出し：

    func(&number);

処理：

    numberのアドレス
          ↓
        コピー
          ↓
          p
          ↓
    *pからnumberへアクセス

`*p` を変更すると、元の `number` が変更される。

---

## 15. returnとポインタの違い

### returnを使う場合

    int changeNumber(int n)
    {
        n = 100;
        return n;
    }

呼び出し：

    number = changeNumber(number);

流れ：

    値を関数へ渡す
        ↓
    関数内で処理
        ↓
    returnで値を返す
        ↓
    呼び出し元で受け取る

---

### ポインタを使う場合

    void changeNumber(int *p)
    {
        *p = 100;
    }

呼び出し：

    changeNumber(&number);

流れ：

    numberのアドレスを渡す
        ↓
    関数がアドレスを受け取る
        ↓
    *pからnumberを直接変更する

この場合は値を `return` する必要がないため、戻り値を `void` にできる。

---

## 16. 今日理解した重要な対応関係

    number
    → 変数の値

    &number
    → numberのメモリアドレス

    p
    → メモリアドレスを保存しているポインタ変数

    *p
    → pが指している場所に保存されている値

関数へ渡す場合：

    func(number)
    → numberの値を渡す

    func(&number)
    → numberのアドレスを渡す

関数側で受け取る場合：

    int n
    → int型の値を受け取る

    int *p
    → int型の変数のアドレスを受け取るポインタ

変更する場合：

    n = 100
    → コピーされたnを変更する

    *p = 100
    → pが指している元の変数を変更する

---

## 17. Day23で特に重要だった理解

### ① 関数の引数は値渡し

普通の変数だけでなく、ポインタを渡す場合も実際には値がコピーされる。

ポインタの場合は「メモリアドレスという値」がコピーされる。

---

### ② 普通の値のコピーとアドレスのコピーは結果が違う

普通の値の場合：

    number = 25
        ↓ コピー
    n = 25

    n = 100

    number = 25

コピー先の `n` を変更しても、元の `number` は変わらない。

ポインタの場合：

    numberのアドレス = 0x1000
             ↓ コピー
    p = 0x1000

    *p = 100

`p` が元の `number` と同じ場所を指しているため、`*p` から元の `number` を変更できる。

---

### ③ returnがなくても元の変数を変更できる

ポインタを使う場合は、

    *p = 値;

によって、呼び出し元の変数そのものを書き換えられる。

そのため、

    void

の関数でも呼び出し元の状態を変更できる。

---

### ④ * の意味は場所によって変わる

    int *p;

→ ポインタ変数の宣言

    *p = 100;

→ pが指している先の値を変更

この2つを区別する。

## Day23 まとめ

Day23では、関数へ普通の値を渡す場合と、ポインタを渡す場合の違いを学習した。

通常の値渡しでは、関数に渡されるのは元の値のコピーなので、関数内で引数を変更しても呼び出し元の変数は変更されない。

一方、

    &変数

で変数のメモリアドレスを関数へ渡し、

    int *p

でそのアドレスを保持するポインタを受け取り、

    *p

を使うことで、関数から呼び出し元の変数を直接変更できる。

ポインタを関数へ渡す場合も、実際にはメモリアドレスという値がコピーされている。

しかし、そのコピーされたアドレスが元の変数が置かれている場所を指しているため、`*p` を通して元の変数へアクセスできる。

また、複数のポインタを引数として渡せば、1つの関数から複数の変数を変更できることも学習した。

最終的には、

    void controlFan(int temperature, int *p);

のように、

- `temperature` は値渡し
- `p` はポインタ

として、1つの関数内で値渡しとポインタを使い分けることができた。
