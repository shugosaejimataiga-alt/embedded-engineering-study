# 1. スコープとは

スコープとは、

**変数名をどこで使えるかという範囲**

のこと。

例えば、

```c
int main(void)
{
    int temperature = 30;

    printf("%d\n", temperature);

    return 0;
}
````

`temperature`は`main`関数の中で宣言されている。

そのため、基本的に`main`関数の中で使用できる。

---

# 2. 変数の寿命とは

変数の寿命とは、

**変数そのものがいつからいつまで存在するか**

という意味。

スコープと寿命は似ているが意味が違う。

* スコープ
  → 変数名を「どこで使えるか」

* 寿命
  → 変数そのものが「いつからいつまで存在するか」

---

# 3. ローカル変数

関数やブロックの中で宣言した変数をローカル変数という。

例：

```c
int main(void)
{
    int temperature = 32;

    return 0;
}
```

`temperature`は`main`関数の中で宣言されているためローカル変数。

`main`関数の外から、

```c
printf("%d\n", temperature);
```

のように使用することはできない。

---

# 4. ブロックスコープ

C言語では、

```c
{
}
```

で囲まれた範囲をブロックという。

ブロックの中で宣言された変数は、そのブロックの中だけで使用できる。

例：

```c
int main(void)
{
    int temperature = 32;

    if (temperature >= 30) {
        int fan = 1;

        printf("%d\n", fan);
    }

    return 0;
}
```

`fan`は`if`文の`{ }`の中で宣言されている。

そのため、

```c
if (temperature >= 30) {
    int fan = 1;
}
```

このブロックを抜けた後に、

```c
printf("%d\n", fan);
```

とすることはできない。

つまり、

```text
{
    int fan = 1;

    ← fanを使える

}

← fanを使えない
```

となる。

---

# 5. グローバル変数

関数の外で宣言した変数を、一般的にグローバル変数という。

例：

```c
#include <stdio.h>

int threshold = 30;

int main(void)
{
    printf("%d\n", threshold);

    return 0;
}
```

`threshold`は関数の外で宣言されているためグローバル変数。

同じファイル内の、宣言より後ろに書かれた関数から使用できる。

---

# 6. ファイルスコープ

関数の外で宣言された変数はファイルスコープを持つ。

例：

```c
#include <stdio.h>

int threshold = 30;

void check(void)
{
    printf("%d\n", threshold);
}

int main(void)
{
    printf("%d\n", threshold);

    check();

    return 0;
}
```

`threshold`は、

* `check`
* `main`

の両方から使用できる。

ただし、正確には

**宣言した位置から、そのファイルの後ろ側**

がスコープになる。

別の`.c`ファイルから使用する方法については、後の`static`や`extern`で学習する。

---

# 7. ローカル変数の寿命

通常のローカル変数は、その変数が属する処理が実行されている間存在する。

例：

```c
int main(void)
{
    int temperature = 32;

    return 0;
}
```

`temperature`は`main`関数内で使用されるローカル変数。

`main`の処理が終了すれば、その変数の寿命も終了する。

---

# 8. ブロック内の変数の寿命

例：

```c
if (temperature >= 30) {
    int fan = 1;

    printf("%d\n", fan);
}
```

`fan`はこのブロック内のローカル変数。

ブロック内で作られ、

```c
}
```

を抜けると寿命が終了する。

---

# 9. グローバル変数の寿命

グローバル変数は、

**プログラム開始からプログラム終了まで存在する。**

例：

```c
int threshold = 30;
```

`threshold`はプログラムが動いている間、存在し続ける。

ここで重要なのは、

```text
スコープ
→ 宣言位置から同じファイル内の後ろ側で変数名を使用できる

寿命
→ プログラム開始からプログラム終了まで存在する
```

という違い。

---

# 10. スコープ外の変数は使用できない

間違った例：

```c
#include <stdio.h>

int main(void)
{
    int temperature = 32;

    if (temperature >= 30) {
        int fan = 1;
    }

    printf("fan = %d\n", fan);

    return 0;
}
```

これはエラーになる。

理由は、

```c
int fan = 1;
```

が`if`文の`{ }`の中で宣言されているため。

`fan`のスコープは、

```c
if (...) {

    int fan = 1;

    // ここでは使用できる

}
```

この中だけ。

正しくするなら、

```c
#include <stdio.h>

int main(void)
{
    int temperature = 32;

    if (temperature >= 30) {
        int fan = 1;

        printf("fan = %d\n", fan);
    }

    return 0;
}
```

のように、`fan`を同じブロック内で使用する。

---

# 11. 3種類の変数を組み合わせた例

```c
#include <stdio.h>

int threshold = 30;

int main(void)
{
    int temperature = 35;

    if (temperature >= threshold) {

        printf("FAN ON\n");

        int fan = 1;

        printf("fan = %d\n", fan);
    }

    return 0;
}
```

それぞれの変数は以下のようになる。

## threshold

```c
int threshold = 30;
```

* グローバル変数
* 関数の外で宣言
* ファイルスコープ
* 宣言位置から同じファイル内の後ろ側で使用できる
* 寿命はプログラム開始からプログラム終了まで

---

## temperature

```c
int temperature = 35;
```

* ローカル変数
* `main`関数の中で宣言
* `main`関数内で使用できる
* `main`の処理中に存在する

---

## fan

```c
int fan = 1;
```

* ローカル変数
* `if`のブロック内で宣言
* 宣言位置から`if`ブロックの最後まで使用できる
* ブロックを抜けると寿命が終了する

# 13. ローカル変数とグローバル変数の違い

| 種類      | 宣言場所     | 主なスコープ       | 寿命            |
| ------- | -------- | ------------ | ------------- |
| ローカル変数  | 関数・ブロック内 | 宣言されたブロック内   | その処理が実行されている間 |
| グローバル変数 | 関数の外     | 宣言位置以降のファイル内 | プログラム開始から終了まで |
