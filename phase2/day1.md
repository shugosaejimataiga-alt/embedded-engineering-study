# 今日やった問題と模範解答

## 問題1

次の説明は正しいか、間違っているか。

> C言語で書いたプログラムは、CPUがそのまま直接読んで実行する。

### 模範解答

間違い。

C言語は人間が読み書きしやすい形で記述するプログラミング言語であり、CPUがそのまま直接実行するものではない。

C言語で書いたソースコードは、GCCなどを使って実行可能な形に変換される。

その後、CPUが機械語の命令を実行する。

```bash

```

2. `gcc` は何をしているか

### 模範解答

## 問題7

次の2つの操作が何をしているか説明する。

```bash
gcc main.c -o hello
```

```bash
./hello
```

### 模範解答

```bash
gcc main.c -o hello
```

は、`main.c` というC言語のソースコードから、`hello` という実行ファイルを作るコマンド。

```bash
./hello
```

は、Linux系OSで、現在のフォルダにある `hello` という実行ファイルを起動するコマンド。

つまり、

```text
gcc main.c -o hello

./hello
→ 実行ファイルを起動する
```

という違いがある。

# 最終問題

C言語で `main.c` を作成し、GCCを使って `hello` という実行ファイルを作り、その `hello` をLinuxで実行する流れを説明する。

説明には以下を含める。

* ソースコード
* GCC
* 実行ファイル
* `./hello`
* OS
* メモリ
* CPU
* 機械語

### 模範解答

ソースコードとは、人間が読み書きできるC言語で記述されたプログラムの元となるコードである。

C言語で書いたソースコードを `main.c` というファイルに保存する。

次に、GCCを使って、

```bash
gcc main.c -o hello
```

を実行する。

これによって、`main.c` のソースコードから `hello` という実行ファイルが作られる。

実行ファイルには、CPUが実行できる機械語の命令などが含まれている。

Linux系OSでは、

```bash
./hello
```

と入力することで、現在のフォルダにある `hello` という実行ファイルを起動できる。

実行ファイルを起動すると、OSが実行に必要な内容をメモリへ読み込み、CPUが機械語の命令を実行する。

流れをまとめると、

```text
C言語でソースコードを書く
↓
main.cとして保存する
↓
GCCで実行ファイルへ変換する
↓
helloという実行ファイルが作られる
↓
./helloで実行ファイルを起動する
↓
OSが実行に必要な内容をメモリへ読み込む
↓
CPUが機械語の命令を実行する
```

# 今日学んだこと

## 1. C言語とは

C言語は、コンピュータに処理をさせるために使うプログラミング言語。

人間が比較的読み書きしやすい形でプログラムを記述できる。

ただし、CPUはC言語をそのまま直接実行することはできない。

C言語で書かれたコードは、実行する前にコンピュータが扱える形へ変換する必要がある。

---

## 2. ソースコードとは

ソースコードとは、人間がプログラミング言語を使って書いたプログラムの元となるコード。

C言語では、例えば次のようなファイルを作る。

```text
main.c
```

`.c` はC言語のソースファイルであることを表す拡張子。

`main.c` の中には、人間がC言語で記述したソースコードが保存されている。

---

## 3. 機械語とは

機械語とは、CPUが実際に実行できる命令。

CPUはC言語をそのまま直接実行するのではなく、最終的には機械語の命令を実行する。

そのため、

```text
C言語
↓
コンピュータが実行できる形へ変換
↓
CPUが機械語を実行
```

という流れになる。

---

## 4. GCCとは

GCCは、C言語で書かれたソースコードから実行ファイルを作るために使うツール。

例えば、

```bash
gcc main.c -o hello
```

と書く。

それぞれの意味は、

```text
gcc
→ GCCを使用する

main.c
→ 変換するソースファイル

-o hello
→ 作成する実行ファイルの名前をhelloにする
```

となる。

---

## 5. 実行ファイルとは

実行ファイルとは、ソースコードをGCCなどで処理して作られる、コンピュータが実行できる形式のファイル。

例えば、

```bash
gcc main.c -o hello
```

を実行すると、

```text
main.c
↓
GCC
↓
hello
```

となり、`hello` という実行ファイルが作られる。

実行ファイルには、CPUが実行できる機械語の命令などが含まれている。

---

## 6. GCCで作ることと実行することは別

GCCで実行ファイルを作っただけでは、そのプログラムはまだ実行されていない。

```bash
gcc main.c -o hello
```

は、

```text
実行ファイルを作る
```

ための操作。

一方、

```bash
./hello
```

は、

```text
作った実行ファイルを起動する
```

ための操作。

この2つは別の処理。

---

## 7. `./hello` の意味

Linux系OSでは、

```bash
./hello
```

と書くことで、現在のフォルダにある `hello` という実行ファイルを起動できる。

```text
hello
→ 実行ファイルの名前

./hello
→ 現在のフォルダにあるhelloを実行する
```

Day1では、`./` の詳しい仕組みまでは扱わず、

```text
Linuxで実行ファイルを起動する書き方
```

として理解した。

---

## 8. 実行ファイルを起動した後の流れ

実行ファイルを起動すると、OSが実行に必要な内容をメモリへ準備する。

その後、CPUが機械語の命令を実行する。

```text
実行ファイルを起動
↓
OSが実行に必要な内容をメモリへ読み込む
↓
CPUが機械語を実行
```

OSは、単純に必ず実行ファイル全体をそのままメモリへコピーするとは限らない。

実際には、実行に必要な部分やライブラリなどを含めてメモリ上へ準備する。

---

## 9. 「プログラム」という言葉

「プログラム」は広い意味で使われる。

ソースコードもプログラムと呼ばれることがあり、実行可能な状態になったものもプログラムと呼ばれる。

そのため、

```text
機械語 = プログラム
```

と完全に同じ意味ではない。

整理すると、

```text
ソースコード
→ 人間が書いたプログラムの元

機械語
→ CPUが実行する命令

実行ファイル
→ 機械語の命令などを含む、実行可能なファイル
```

となる。
