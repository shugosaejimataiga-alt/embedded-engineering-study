# C-Day19：文字列

## 学習内容

C言語における文字列の基本を学習した。

今回の主な内容は以下。

- `char` 型
- `char` 配列
- 文字と文字列の違い
- 終端文字 `\0`
- 文字列の各文字へのアクセス
- `%c` と `%s` の使い分け
- `for` 文を使った文字列の走査

---

# 1. char型

`char` は1文字を扱うために使用できる整数型。

    char letter = 'A';

1文字を表す場合は、シングルクォート `' '` を使用する。

例：

    'A'
    'B'
    '7'

1文字を `printf` で表示する場合は `%c` を使用する。

    char letter = 'A';

    printf("%c\n", letter);

出力：

    A

---

# 2. 文字列はchar配列で扱う

C言語には、基本データ型としての `string` 型はない。

文字列は `char` 型の配列として扱う。

    char word[] = "SENSOR";

`"SENSOR"` のように文字列を書く場合は、ダブルクォート `" "` を使用する。

---

# 3. 文字と文字列の違い

## 文字

    char letter = 'A';

`'A'` は1文字。

シングルクォートを使用する。

## 文字列

    char word[] = "A";

`"A"` は文字列。

ダブルクォートを使用する。

文字列の場合は、実際には以下のようになっている。

    word[0] = 'A'
    word[1] = '\0'

そのため、

    'A'

と

    "A"

は同じものではない。

---

# 4. 終端文字 `\0`

C言語の文字列の最後には、

    '\0'

という終端文字が入る。

これは、

「この位置で文字列が終わる」

ことを表す特殊な文字。

例えば、

    char word[] = "FAN";

の場合、内部では以下のようになる。

    word[0] = 'F'
    word[1] = 'A'
    word[2] = 'N'
    word[3] = '\0'

つまり、

    F A N \0

の4要素が存在する。

---

# 5. 文字数と配列の要素数

文字列では、文字数と配列の要素数が同じとは限らない。

例えば、

    char word[] = "HELLO";

の場合、

    文字数      = 5
    配列要素数  = 6

となる。

内部では、

    word[0] = 'H'
    word[1] = 'E'
    word[2] = 'L'
    word[3] = 'L'
    word[4] = 'O'
    word[5] = '\0'

となっている。

したがって基本的には、

    文字列の配列要素数
    =
    文字数 + 終端文字1個

となる。

---

# 6. 配列の要素数と添字

例えば、

    int numbers[5];

の場合、

    5個分の要素を用意する

という意味。

ただし、配列の添字は `0` から始まる。

    numbers[0]  ← 1個目
    numbers[1]  ← 2個目
    numbers[2]  ← 3個目
    numbers[3]  ← 4個目
    numbers[4]  ← 5個目

つまり、

    要素数 = 5個
    使用できる添字 = 0～4

となる。

最後の添字は、

    要素数 - 1

になる。

これはC言語が自動的に1を引いているのではなく、

    添字が0から始まる

ことによる結果。

---

# 7. char配列でも添字を使える

文字列も `char` 配列なので、通常の配列と同じように添字を使える。

    char word[] = "DOG";

内部では、

    word[0] = 'D'
    word[1] = 'O'
    word[2] = 'G'
    word[3] = '\0'

となる。

例えば、

    printf("%c\n", word[1]);

とすると、

    O

が表示される。

---

# 8. `%c` と `%s` の違い

文字と文字列では `printf` の指定子を使い分ける。

## `%c`

1文字を表示する。

    printf("%c\n", word[0]);

例えば、

    D

のように1文字を表示する。

## `%s`

文字列全体を表示する。

    printf("%s\n", word);

例えば、

    DOG

と表示される。

## 覚え方

    %c → character → 1文字
    %s → string → 文字列全体

また、

    word      → 文字列全体
    word[i]   → 配列の中の1文字

と考える。

---

# 9. 文字列を1文字ずつ表示する

文字列の各文字は添字を使って取り出せる。

    char word[] = "FAN";

    printf("%c\n", word[0]);
    printf("%c\n", word[1]);
    printf("%c\n", word[2]);

出力：

    F
    A
    N

---

# 10. for文で1文字ずつ処理する

文字列も配列なので、`for` 文を使って順番に処理できる。

    char word[] = "FAN";

    for (int i = 0; i < 3; i++) {
        printf("%c\n", word[i]);
    }

この場合、

    i = 0
    i = 1
    i = 2

と変化し、

    word[0]
    word[1]
    word[2]

を順番に処理している。

---

# 11. `\0` を利用した文字列の走査

文字数を直接指定せず、`\0` が現れるまで繰り返すこともできる。

    char word[] = "STOP";

    for (int i = 0; word[i] != '\0'; i++) {
        printf("%c\n", word[i]);
    }

条件、

    word[i] != '\0'

は、

    現在の文字が終端文字ではない間

という意味。

処理の流れ：

    word[0] → 'S'  → \0ではない → 処理
    word[1] → 'T'  → \0ではない → 処理
    word[2] → 'O'  → \0ではない → 処理
    word[3] → 'P'  → \0ではない → 処理
    word[4] → '\0' → 条件が偽     → 終了

文字列の長さを直接書かなくても、文字列の最後まで処理できる。

---

# 12. 文字列全体と1文字の違い

例えば、

    char word[] = "CAT";

文字列全体を表示する場合：

    printf("%s\n", word);

出力：

    CAT

1文字だけ表示する場合：

    printf("%c\n", word[1]);

出力：

    A

1文字ずつ順番に表示する場合：

    for (int i = 0; word[i] != '\0'; i++) {
        printf("%c\n", word[i]);
    }

出力：

    C
    A
    T

整理すると、

    word
    → 文字列全体

    word[i]
    → 文字列の中の1文字

となる。

---

# 13. 文字列を1文字ずつ配列へ書く方法

文字列は、

    char word[] = "GO";

のように書く以外にも、1文字ずつ配列へ入れることができる。

    char word[] = {'G', 'O', '\0'};

内部の状態は、

    word[0] = 'G'
    word[1] = 'O'
    word[2] = '\0'

となる。

つまり、

    char word[] = "GO";

と、

    char word[] = {'G', 'O', '\0'};

は、文字列として同じ内容になる。

---

# 14. `\0` を自分で書く場合

文字列リテラルを使う場合、

    char word[] = "GO";

終端文字 `\0` は自動的に追加される。

実際には、

    'G'
    'O'
    '\0'

となる。

一方、

    char word[] = {'G', 'O', '\0'};

のように1文字ずつ配列を初期化する場合は、文字列として扱うために自分で `'\0'` を入れる。

---

# 15. `\0` が必要な理由

例えば、

    printf("%s\n", word);

で文字列を表示するとき、`printf` は配列の中を順番に読み、`\0` を見つけることで、

    ここで文字列が終わる

と判断する。

そのため、

    char word[] = {'G', 'O'};

のように終端文字がない配列を文字列として `%s` で扱うと、文字列がどこで終わるのか判断できない。

その結果、配列の外側にある関係ないメモリまで読み込む可能性がある。

文字列として扱う場合は `\0` が重要。

---

# 16. 配列の要素数を省略した場合

    char word[] = "FAN";

のように配列の要素数を書かなかった場合、必要な要素数は自動的に決まる。

`"FAN"` の場合、

    'F'
    'A'
    'N'
    '\0'

なので、4要素分が確保される。

つまり、

    char word[] = "FAN";

では、配列は4要素になる。

---

# 17. 今回整理した重要な3パターン

## ① 文字列全体を扱う

    printf("%s\n", word);

## ② 配列の中の1文字を扱う

    printf("%c\n", word[i]);

## ③ 文字列を1文字ずつ順番に処理する

    for (int i = 0; word[i] != '\0'; i++) {
        printf("%c\n", word[i]);
    }

この3つを区別することが重要。

---

# 18. Day19で特に重要だった理解

今回特に重要だったのは、

    word

と、

    word[i]

の違い。

    word
    → 文字列全体

    word[i]
    → 文字列を構成する1文字

そのため、

    word    → %s
    word[i] → %c

と使い分ける。

---

# 19. Day19まとめ

C言語では文字列を `char` 配列として扱う。

重要事項：

    'A'
    → 1文字
    → シングルクォート

    "A"
    → 文字列
    → ダブルクォート

文字列は、

    文字
    文字
    文字
    ...
    \0

という構造になっている。

例えば、

    char word[] = "BOOK";

なら、

    word[0] = 'B'
    word[1] = 'O'
    word[2] = 'O'
    word[3] = 'K'
    word[4] = '\0'

となる。

また、

    %s → 文字列全体
    %c → 1文字

であり、

    word    → 文字列全体
    word[i] → 1文字

と考える。

文字列を順番に処理するときは、

    for (int i = 0; word[i] != '\0'; i++)

とすることで、終端文字まで処理できる。
