# 1. strlen

`strlen` は、文字列の長さを調べるための関数。

使用するには、

```c
#include <string.h>
```

が必要。

基本形：

```c
strlen(文字列);
```

例：

```c
char word[] = "SENSOR";

printf("%zu\n", strlen(word));
```

結果：

```text
6
```

## strlenが数えるもの

`strlen` は、

**文字列の先頭から最初の `\0` までのバイト数**

を数える。

`'\0'` 自体は含めない。

例：

```c
char word[] = "ABC";
```

メモリ上では、

```text
'A' 'B' 'C' '\0'
```

となっている。

そのため、

```c
strlen(word)
```

の結果は、

```text
3
```

となる。

---

# 2. strlenの戻り値はsize_t

`strlen` が返す値の型は、

```c
size_t
```

である。

例：

```c
size_t length = strlen(word);
```

`size_t` は、

**メモリの大きさや個数などを表すために使われる整数型**

と考える。

`size_t` を `printf` で表示するときは、

```c
%zu
```

を使用する。

例：

```c
printf("%zu\n", strlen(word));
```

整理：

```text
int     → %d
size_t  → %zu
```

---

# 3. sizeof

`sizeof` は、

**変数や配列そのものがメモリ上で何バイト使用しているか**

を調べる。

`sizeof` はC言語そのものの機能なので、専用のヘッダーファイルは必要ない。

例：

```c
char word[] = "ABC";
```

メモリ上では、

```text
'A' 'B' 'C' '\0'
 1   1   1    1 byte
```

となる。

そのため、

```c
sizeof(word)
```

は、

```text
4
```

となる。

---

# 4. strlenとsizeofの違い

例：

```c
char word[] = "ABC";
```

の場合、

```text
strlen(word) → 3
sizeof(word) → 4
```

となる。

## strlen

```text
最初の \0 までのバイト数を数える
\0 自体は含めない
```

## sizeof

```text
変数・配列そのものがメモリ上で占めるバイト数を調べる
```

文字列配列の場合、配列の中に `\0` も存在するため、その分も含まれる。

ただし、`sizeof` が「必ず `\0` を含めて数える機能」というわけではない。

あくまで、

**指定した変数や配列全体のサイズを調べている**

ということ。

---

# 5. char配列の大きさを指定する

これまでは、

```c
char word[] = "SENSOR";
```

のように書いていた。

この場合は最初から文字列が入っているので、C言語側が必要な配列サイズを自動的に決める。

`"SENSOR"` の場合、

```text
'S' 'E' 'N' 'S' 'O' 'R' '\0'
```

なので7バイト必要になる。

一方、

```c
char name[20];
```

と書くと、

**char型の領域を20個分確保する**

という意味になる。

`char` は1個1バイトなので、

```c
char name[20];
```

では20バイト確保される。

これは、後からユーザーに文字列を入力してもらう場合などに使用する。

# 6. fgets

`fgets` は、

**プログラム実行中にユーザーから文字列を入力してもらうための関数**

である。

ゲームで考えると、プレイヤーが自分の名前やコマンドを入力する場合などに使用できる。

基本形：

```c
fgets(保存先, 保存先の大きさ, 入力元);
```

例：

```c
char name[20];

fgets(name, sizeof(name), stdin);
```

それぞれの意味：

```text
name
→ 入力された文字列の保存先

sizeof(name)
→ name全体で何バイト使用できるか

stdin
→ 標準入力
→ 通常はキーボードからの入力
```

つまり、

```c
fgets(name, sizeof(name), stdin);
```

は、

**キーボードから入力された文字列を、nameの大きさを超えないようにnameへ保存する**

という意味になる。

---

# 7. stdin

`stdin` は、

```text
standard input
```

の略。

日本語では、

```text
標準入力
```

という。

通常のプログラムでは、

```text
stdin
→ ユーザーがキーボードから入力する
```

と考えてよい。

---

# 8. ソースコードに書く文字列とfgetsの違い

例えば、

```c
char word[] = "AUTO";
```

の場合、

`"AUTO"` はプログラムを作成している人が、ソースコードを書く段階で決めている。

つまり、プログラム実行前から値が決まっている。

一方、

```c
char word[20];

fgets(word, sizeof(word), stdin);
```

では、

**プログラムを実行した後にユーザーが文字列を入力できる。**

整理：

```text
char word[] = "AUTO";

→ プログラムを書く段階で値を決める


fgets(word, sizeof(word), stdin);

→ プログラム実行中にユーザーが値を入力する
```

---

# 9. fgetsと改行文字 \n

`fgets` では通常、ユーザーがEnterを押したときの改行文字 `\n` も配列に保存される。

例えばユーザーが、

```text
TARO + Enter
```

と入力すると、

```text
'T' 'A' 'R' 'O' '\n' '\0'
```

のように保存される。

使用するバイト数は、

```text
T → 1バイト
A → 1バイト
R → 1バイト
O → 1バイト
\n → 1バイト
\0 → 1バイト
```

なので、合計6バイトとなる。

つまり、通常の `fgets` の入力では、

```text
入力した文字
+
\n
+
\0
```

が配列に入ることを意識する。

---

# 10. fgetsで使用できる文字数

例えば、

```c
char word[20];
```

では20バイト確保される。

文字列には最後の `\0` が必要なので、最大でも、

```text
19バイト分のデータ
+
\0
```

という形になる。

さらに通常はEnterによる `\n` も保存されるため、

```text
入力した文字
+
\n
+
\0
```

という構成になることがある。

# 11. strcspn

`fgets` で入力された `\n` を削除するときに、

```c
strcspn
```

を使用した。

使用するには、

```c
#include <string.h>
```

が必要。

使用例：

```c
name[strcspn(name, "\n")] = '\0';
```

---

# 12. strcspnによる改行削除の仕組み

例えば、

```text
'A' 'U' 'T' 'O' '\n' '\0'
```

という文字列がある。

添字は、

```text
'A'  → 0
'U'  → 1
'T'  → 2
'O'  → 3
'\n' → 4
```

となる。

ここで、

```c
strcspn(name, "\n")
```

を使用すると、最初の `\n` がある位置を調べられる。

今回なら、

```text
4
```

となる。

したがって、

```c
name[strcspn(name, "\n")] = '\0';
```

は、

```c
name[4] = '\0';
```

という処理になる。

変更前：

```text
'A' 'U' 'T' 'O' '\n' '\0'
```

変更後：

```text
'A' 'U' 'T' 'O' '\0' '\0'
```

文字列としては、

```text
AUTO
```

になる。

つまり、

**`\n` を `\0` に置き換えることで、入力時の改行を文字列から取り除いている。**

---

# 13. なぜfgetsの\nを削除するのか

例えばユーザーが、

```text
START + Enter
```

と入力すると、通常は、

```text
"START\n"
```

として保存される。

この状態で、

```c
strcmp(word, "START")
```

とすると、

```text
word      → "START\n"

比較対象    → "START"
```

となる。

文字列の中身が違うため、一致しない。

そのため、

```c
word[strcspn(word, "\n")] = '\0';
```

として、

```text
"START\n"
↓
"START"
```

にしてから比較する。

---

# 14. strcmp

`strcmp` は、

**2つの文字列の中身を比較する関数**

である。

使用するには、

```c
#include <string.h>
```

が必要。

基本形：

```c
strcmp(文字列1, 文字列2);
```

2つの文字列が完全に同じ場合、

```text
0
```

を返す。

例：

```c
strcmp("AUTO", "AUTO")
```

の結果は、

```text
0
```

となる。

そのため、

```c
if (strcmp(mode, "AUTO") == 0) {
    printf("AUTO MODE\n");
}
```

と書くことで、

**modeの中身が `"AUTO"` と完全に同じ場合**

という条件を作れる。

---

# 15. strcmpはバイト数を比較する関数ではない

`strcmp` は、

**文字列の中身そのもの**

を比較する。

例えば、

```text
CAT
DOG
```

は両方とも3バイトだが、中身は違う。

そのため、

```c
strcmp("CAT", "DOG")
```

は `0` にならない。

整理：

```text
strcmp
→ 文字列のバイト数だけを比べるわけではない
→ 文字列の中身を比較する
→ 完全に同じなら0を返す
```

---

# 16. なぜ文字列を==で比較しないのか

数値なら、

```c
if (number == 10)
```

と比較できる。

文字1個なら、

```c
if (ch == 'A')
```

と比較できる。

しかし、文字列の場合、

```c
if (mode == "AUTO")
```

では、文字列の中身を正しく比較できない。

`==` を文字列に対して使用すると、

**文字列の中身ではなく、保存されている場所（アドレス）を比較することになるため。**

そのため、文字列の中身を比較したい場合は、

```c
strcmp(mode, "AUTO") == 0
```

を使用する。

整理：

```text
数値
→ ==

文字1個
→ ==

文字列
→ strcmp
```

---

# 17. fgets・strcspn・strcmpの流れ

ユーザーから文字列を入力して、その内容によって処理を変える場合の基本的な流れは、

```text
ユーザーが文字列を入力
        ↓
fgetsで配列へ保存
        ↓
strcspnで \n の位置を探す
        ↓
\n を \0 に置き換える
        ↓
strcmpで文字列の中身を比較
        ↓
条件に応じて処理を実行
```

となる。

例：

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char mode[20];

    fgets(mode, sizeof(mode), stdin);

    mode[strcspn(mode, "\n")] = '\0';

    if (strcmp(mode, "AUTO") == 0) {
        printf("AUTO MODE\n");
    }

    return 0;
}
```
